## 5. How a root-absolute asset is served (the model for `/assets/mbm-tokens.css`)

- `hud.js` lives in the **site** repository (33,966 B), not in Lessons, and 544 Lessons
  HTML files load it as `src="/hud.js"` — 23 of them under `Games/`.
- `domain-split/build_publications.py:290` copies the **whole `assets/` directory**
  into the composed play tree (`for directory in ['assets','images']: copytree`).
  So a new `assets/mbm-tokens.css` reaches Play with **no build change at all**, which
  is what T4's "on the composed Play tree /assets/mbm-tokens.css resolves" needs.
- The education trees do not copy wholesale: they admit file by file through
  `domain-split/education-publication-admission.json` (55 `assets/` paths in
  education-site today, 18 in education-lessons). The token file therefore needs
  exactly one registry entry per tree that links it.
