Every ASDAN slot, one connected system. Reluctant writers build real qualifications through making, doing and photographing — not paperwork.

Shared blueprint (every pack): a title illustration + warm-up → a different settle activity each week (wordsearch, match-up, odd-one-out, sequence, sort, team quiz) → ▣ MODEL (I do / we do) → ◆ INDEPENDENT (you do — Standard or Supported) → the Lundy loop onto a term-long class artefact → Evidence & review (Documentarian photos, annotated visuals, witness-statement shorthand → ASDAN tracker + predicted grade). Zones are icon+label+colour (never colour alone), Calm Mode + print built in, no pupil names.
