A small plan that helps

Autumn 2 · Week 1 · 40 minutes

Learning intention

I can plan a small task that helps our class.

Success criteria

  • Spot what needs to change.
  • Choose a task that fits the kit.
  • Show how we could check it.

Use Next to begin. Ask for word help or your usual support when needed.

BUILD · A small plan that helps

Autumn 2 · Week 1

SoW

BUILD Weekly - Autumn!B151, C151

  • Plan a class community/social-action project (Anti-Bullying/Kindness).

Aut2 W1; current calendar absolute W9. This is a classroom teaching and planning lesson. It makes no claim of community impact or qualification completion.

Prior: Draw on familiar class jobs. If the pupil has not met need/idea/check, use the supplied examples rather than assuming prior teaching.

Next: Next week, agree a clear goal and choose useful roles for the choice-board project.

Preparation

  • Print game and club cards, option cards and blank plan. Cut with adult support if needed; cards can also be pointed to uncut.

Care and safety

  • Core activities stay on the classroom table using the supplied paper resources. No public contact, sales, spending, photographs or personal disclosures are required.
  • For a real follow-on project, staff confirm the purpose, materials and audience within the school’s existing arrangements.

Teacher response guidance

  • The brief concerns unlabelled boxes, not a requirement to join a game.
  • Guided: A, kit 1, check 1. The check tests finding a named game, while liking a decoration is a different question.
  • Independent: name-and-picture club cards with a find-READ check fit; other small label formats are valid if explained. No impact result is supplied.

Evidence of learning

Look for the pupil’s own link between the stated need, a feasible task and a relevant check. These tasks are teaching/rehearsal. Use only the learner’s actual contribution; no automatic award sign-off is implied.

Access and independence

Read the brief in short chunks. Offer pointing, exact-word scribing or drawing. Keep the same need-to-check thinking in every route.

Lundy Loop

Receive the pupil’s proposed check. If it only asks whether a design is liked, return to the missing label and ask what the user needs to find.

Arrival · What could help?

Three quick retrieval opportunities, then lead-in. Accept uncertain responses; use them to choose a cue.

Starter · A shelf with no names

Read the fictional visitor quote neutrally. This is a made-up situation, not a bullying disclosure.

I do · Need, task, check

Model one chess card only. A colourful border may be pleasant but does not name the boxes. Keep “could help”, not “has helped”.

We do · Choose a useful plan

Use the interactive three-part plan. Ask why the selected task fits before checking.

I do · A check we can trust

Model the difference between liking the artwork and finding the named game. If using the paper cards, this can be a real classroom check. No class result is prefilled.

We do · Keep the choice open

A helpful choice board offers access; it does not require participation. Receive a pupil suggestion for a pass route.

Independent · Plan the class-club cards

Fresh club context avoids copying the guided chess answer. Use exact pupil words and retain the pupil’s design decision.

Exit · Tell us your next step

Adult names the actual link heard and changes next week’s role/material setup in response. No written reflection requirement.

Misconceptions

Kindness means making someone join. A kind action preserves their choice.

Any bright design solves the need. Check whether it helps someone find the named box.
