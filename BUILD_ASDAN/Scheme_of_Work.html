BUILD ASDAN — Scheme of Work (Autumn 1)

One connected system across all six ASDAN slots · SEMH alternative provision

Shared blueprint (every lesson — Studio Deck v2): a slide deck with its own illustration: title & settle → warm-up quick-four → a spark statement → ▣ MODEL zone (I do / we do) → a different settle activity each week (W1 wordsearch · W2 match-up · W3 odd-one-out · W4 sequence · W5 sort · W6 team quiz — all click-only, no timers, no scores) → ◆ INDEPENDENT zone (Standard/Supported) → the Lundy loop onto a term-long class artefact (Strengths Wall · Money-Smart Board · Balanced-Plate Gallery · Project Board · Challenge Wall) → Evidence & review (Documentarian photos, annotated visuals, witness-statement shorthand → ASDAN tracker + predicted grade). Zones are icon + label + colour (colourblind-safe); Calm Mode, reduced-motion and print built in; no pupil names.

Launch-level evidence engine: every lesson banks portfolio evidence as it happens — a rotating Documentarian photographs the work (Lundy Voice), photos are annotated not written up, and pre-printed witness-statement shorthand lets staff tick the exact ASDAN competency, sign and file. Each lesson names the ASDAN module/challenge it banks.

Connected: every lesson has prev/next nav; each slot has a hub; one master BUILD ASDAN Hub links all six slots. Weeks 7–8 are consolidation & portfolio completion.
