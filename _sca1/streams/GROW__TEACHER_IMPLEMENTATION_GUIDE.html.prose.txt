Alternative 40-minute route for GROW Science Aut 1 W3–W7. The existing route remains available in the Lessons catalogue.
Teacher implementation guide
How to run the v3 lessons as a coherent GROW Science teaching system.
The non-negotiable 40-minute grammar
Explore:
4 Arrival + 4 Starter + 5 I Do + 5 We Do + 4 I Do 2 + 4 We Do 2 + 10 Independent + 4 Exit = 40 minutes.
Do:
3 Arrival + 3 Starter + 4 I Do + 4 We Do + 3 I Do 2 + 4 We Do 2 + 15 Independent + 4 Exit = 40 minutes.
What makes v3 distinctive
Visual hooks are local and teacher-controlled; official Oak media is optional. Every graphical or interactive element serves a prediction, misconception, model, decision or explanation. Hands-on work is used whenever it makes the invisible Science visible or creates better evidence. Support routes change modality and scaffolding without lowering the learning goal.
Feedback as participation
Run SPACE → VOICE → AUDIENCE → INFLUENCE repeatedly. A pupil answer is not the end of a check: it changes the next question, scaffold, explanation or task. Use the staff Live Loop button to decide the learning move; nothing is stored.
Evidence rule
Prefer a three-part trace: pupil decision/prediction → observable action/product/result → pupil explanation/evaluation/next step. A photo by itself is not enough. The separate end-of-day window supports lean same-day evidence handling where the school policy requires it.

Hands-on resources
Evidence target
W3A
Grip Lab: why do some surfaces save us from slipping?
Trainer sole or rubber, smooth plastic/laminate, fabric/carpet, rough card/sandpaper, everyday friction picture cards.
Annotated friction detective card or photo/model paired with the pupil’s explanation.
W3B
Surface Test Lab: can our evidence identify the grippiest surface?
Small trolley/block, ramp or fixed release method, three safe surfaces, metre rule/tape, results table, tray.
Prediction + results table + conclusion; photo only when paired with learner reasoning.
W4A
Mechanism Hunt: find the hidden force advantage in everyday objects.
Ruler and pivot, scissors (adult-controlled as needed), bottle opener, spanner, bicycle/gear images, rope/pulley image or simple pulley.
Mechanism classification plus pivot/turning annotation and gain/trade-off explanation.
W4B
Lift It Smarter: investigate where the pivot should go.
Rulers/wood strips, stable pivots, light loads, trays, ruler/tape and optional spring balance.
Two or three pivot setups + effort/distance evidence + pupil conclusion.
W5A
Science Detective: repair a test that cannot answer its own question.
Variable cards, three-box planning frame, trolley/ramp as a brief demo, unit cards, example result slips.
Pupil-authored plan showing change / measure + unit / controls / repeats.
W5B
Evidence Lab: can another scientist trust our results?
Trolley/block, ramp, three surfaces, metre rules/tapes, prepared repeat table, calculators optional.
Plan + raw repeat data + conclusion + evaluation kept together.
W6A
Mission Control: navigate the eight-planet Solar System.
Eight planet cards/counters, large Sun card, arrows/labels, optional string orbit, desk/floor model space.
Ordered Solar System strip/model + classification + gravity/motion explanation.
W6B
Build Mission Control: make a model that tells the truth about what it represents.
Planet cards/balls, Sun marker, labels, tape/string, large paper and force/motion arrows.
Model photo/drawing + annotated gravity/motion arrows + one model limitation.
W7A
Moon Detective: why does the Moon seem to change shape?
Torch/lamp, foam ball, Earth/observer marker, four/eight phase cards, bright-room diagram alternative.
Phase sequence/model + reflected-light explanation + phase/eclipses distinction.
W7B
Lunar Studio: use a model to make the phases appear on command.
Torches/lamps, foam balls, phase-wheel sheets/cards, pencils and split pins/clips if building wheels.
Phase wheel/model record + sunlight direction + learner explanation and model limitation.
