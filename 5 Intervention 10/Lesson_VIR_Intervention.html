I Do · I teach

Circuit rules: series vs parallel

Watch the orange flow — that's the current moving round.

🔗 Series (one loop)

Current: the SAME everywhere 🔁
Voltage: SHARED across components (adds up)
Resistance: ADD them → R = R₁ + R₂

🪢 Parallel (branches)

Current: SHARED between branches (splits)
Voltage: the SAME across each branch 🔁
Resistance: total goes DOWN (more paths)
🚫 Common misconception

"Current gets used up as it goes round the circuit."

✓ Truth: in a series circuit the current is the same all the way round. The energy (voltage) is what gets shared out.
