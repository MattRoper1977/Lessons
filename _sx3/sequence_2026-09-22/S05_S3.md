## What it does

A Science pack's `SHA256SUMS.txt` is declared in the same transaction as the decks it lists, and
only as the derivation of their re-cut bytes:
- the row set never moves;
- every changed line is the same row with only its digest replaced;
- every declared deck's row equals its bytes;
- a row stale at the base may ride along (D-1); a row fresh at the base, or whose file changed
  outside the transaction, is refused;
- a deck whose manifest lists it but is not re-cut is refused, even if the branch renamed or
  removed the manifest;
- a deck with no row (a Classic) is not enrolled (correction #32);
- the manifest must be pinned like every member.

`derive()` is now `strand_kinds` / `diff_statuses` / `strand_landable`, with `root`, `registry`
and `deck_limb` seams. The self-test runs `derive()` itself against a throwaway git repository. That
repository is isolated from the caller's git environment, its commits are unsigned, and its named
base differs from its merge base.
