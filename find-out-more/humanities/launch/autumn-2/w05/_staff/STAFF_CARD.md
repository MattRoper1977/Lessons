# LAUNCH_HUM_A2_W05 · Progress Schools staff card

**Scheme objective:** Record fieldwork in a spreadsheet and graph it.

**Run it without a worksheet:** Display the poster and name the learning goal. Read one source chunk on the shared screen; learners find the three answers by speech, pointing, signing, symbol/AAC, drawing or writing. Use Read it back (?) on one sentence; let the pupil correct or extend an answer. Use the reading ruler or device text-to-speech when helpful. Staff device (school tablet) or projector only. An adult fades prompts as soon as the pupil can proceed.

**Four pupil-voice answers this topic enables:**
1. Learning: “I am learning to turn a fieldwork tally into a labelled graph.”
2. Feedback: “I was asked to check the source detail for: What should an axis show?”
3. Improvement: “I will add or correct the detail I found for: How is a graph checked?”
4. Success: “I can answer all three questions and use a source detail for the scenario.”

**Expected source anchors (not a script to give away):**
- Where do graph values come from? — The values come from the tally table.
- What should an axis show? — An axis names what is counted.
- How is a graph checked? — Check every bar against the original tally.

**Accepted response routes:** verbal; demonstrated/pointed; signed; symbol/AAC; drawn; written. Record the route and prompt actually used in the existing record.

**Full feedback code set in this activity:**
- **VF:** Adult gives spoken feedback on one source-linked answer.
- **WS:** Pupil works with the adult's reading or choice support; record the support used.
- **I:** Pupil locates a source detail or answers without a content prompt.
- **NS+:** Ask for one specific next step: find the source line for “How is a graph checked?” and add its detail.
- **E:** E: evidence captured on Cypher
- **R:** Next lesson, receive and attend to the pupil's response to NS+ before marking the loop closed.
- **//:** Mark the exact point in the existing response where the pupil self-edits.
- **?:** Use Read it back; pupil reads, hears or indicates the highlighted sentence and checks their claim.

**Loop:** NS+ → pupil responds in their own mode → adult listens/looks and acts as Audience → R, normally revisited next lesson. A feedback mark alone is not R.

**Pathway expectation:** Pathways: high support, VF/WS · Build: mix of WS and I, can explain feedback · Grow: mostly independent, self-editing, NS and R · Launch: independent, self-assessing.

**Possible EHCP broad-area tag if an actual relevant behaviour is observed:** communication & interaction; cognition & learning. An observable example is locating a source line for “What should an axis show?” and communicating its meaning with the support level noted. This is not an invented outcome or proof of one.

**TA prompts, least first (stop and fade when the pupil acts):**
1. “Which line might help with the first question?”
2. “Where does the page use the word table?”
3. “Can you point to the sentence that could answer ‘How is a graph checked?’?”

**Stretch:** How could a neat graph still misrepresent the fieldwork?

**Way in:** Start with one category and count the tally marks.

**Image brief:** A small tally table beside a bar graph with the same two category labels and values. Add only a licensed or original image and the matching Widgit symbols if the poster is landed.
