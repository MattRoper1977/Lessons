# BUILD_HUM_A2_W07 · Progress Schools staff card

**Scheme objective:** Make a festivals display and gather UAS evidence.

**Run it without a worksheet:** Display the poster and name the learning goal. Read one source chunk on the shared screen; learners find the three answers by speech, pointing, signing, symbol/AAC, drawing or writing. Use Read it back (?) on one sentence; let the pupil correct or extend an answer. Use the reading ruler or device text-to-speech when helpful. Staff device or projector only. An adult fades prompts as soon as the pupil can proceed. Use this source reading before or after the formal check; permitted access arrangements govern assessed work.

**Four pupil-voice answers this topic enables:**
1. Learning: “I am learning to choose evidence for a festival display.”
2. Feedback: “I was asked to check the source detail for: What should an object label show?”
3. Improvement: “I will add or correct the detail I found for: How do we check a meaning claim?”
4. Success: “I can answer all three questions and use a source detail for the scenario.”

**Expected source anchors (not a script to give away):**
- What should a display name? — A display names the festival and source.
- What should an object label show? — A lamp label tells us what object is shown.
- How do we check a meaning claim? — A meaning claim is checked against the named account.

**Accepted response routes:** verbal; demonstrated/pointed; signed; symbol/AAC; drawn; written. Record the route and prompt actually used in the existing record.

**Full feedback code set in this activity:**
- **VF:** Adult gives spoken feedback on one source-linked answer.
- **WS:** Pupil works with the adult's reading or choice support; record the support used.
- **I:** Pupil locates a source detail or answers without a content prompt.
- **NS+:** Ask for one specific next step: find the source line for “How do we check a meaning claim?” and add its detail.
- **E:** E: evidence captured on {EVIDENCE_APP}
- **R:** Next lesson, receive and attend to the pupil's response to NS+ before marking the loop closed.
- **//:** Mark the exact point in the existing response where the pupil self-edits.
- **?:** Use Read it back; pupil reads, hears or indicates the highlighted sentence and checks their claim.

**Loop:** NS+ → pupil responds in their own mode → adult listens/looks and acts as Audience → R, normally revisited next lesson. A feedback mark alone is not R.

**Pathway expectation:** Pathways: high support, VF/WS · Build: mix of WS and I, can explain feedback · Grow: mostly independent, self-editing, NS and R · Launch: independent, self-assessing.

**Possible EHCP broad-area tag if an actual relevant behaviour is observed:** communication & interaction; cognition & learning. An observable example is locating a source line for “What should an object label show?” and communicating its meaning with the support level noted. This is not an invented outcome or proof of one.

**TA prompts, least first (stop and fade when the pupil acts):**
1. “Which line might help with the first question?”
2. “Where does the page use the word source?”
3. “Can you point to the sentence that could answer ‘How do we check a meaning claim?’?”

**Stretch:** Which caption is informative without overgeneralising?

**Way in:** Choose one object, one label and one matching source line.

**Image brief:** A three-panel display plan: named source, light object, and one sourced meaning. Add only a licensed or original image and the matching Widgit symbols if the poster is landed.
