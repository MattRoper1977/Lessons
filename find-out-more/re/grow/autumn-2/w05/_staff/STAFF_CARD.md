# GROW_RE_A2_W05 · Progress Schools staff card

**Scheme objective:** Ask or answer a respectful question and record one thing learned from a faith or belief visitor.

**Run it without a worksheet:** Display the poster and name the learning goal. Read one source chunk on the shared screen; learners find the three answers by speech, pointing, signing, symbol/AAC, drawing or writing. Use Read it back (?) on one sentence; let the pupil correct or extend an answer. Use the reading ruler or device text-to-speech when helpful. Staff device or projector only. An adult fades prompts as soon as the pupil can proceed. In RE, report what the named religious and non-religious sources say; do not ask pupils what they believe.

**Four pupil-voice answers this topic enables:**
1. Learning: “I am learning to form a respectful question for a faith or belief source.”
2. Feedback: “I was asked to check the source detail for: What should a reply identify?”
3. Improvement: “I will add or correct the detail I found for: What should not be assumed?”
4. Success: “I can answer all three questions and use a source detail for the scenario.”

**Expected source anchors (not a script to give away):**
- What should a question ask about? — Ask what a named source says or does.
- What should a reply identify? — Record one new fact from the reply or text.
- What should not be assumed? — Do not assume one voice speaks for everyone.

**Accepted response routes:** verbal; demonstrated/pointed; signed; symbol/AAC; drawn; written. Record the route and prompt actually used in the existing record.

**Full feedback code set in this activity:**
- **VF:** Adult gives spoken feedback on one source-linked answer.
- **WS:** Pupil works with the adult's reading or choice support; record the support used.
- **I:** Pupil locates a source detail or answers without a content prompt.
- **NS+:** Ask for one specific next step: find the source line for “What should not be assumed?” and add its detail.
- **E:** E: evidence captured on {EVIDENCE_APP}
- **R:** Next lesson, receive and attend to the pupil's response to NS+ before marking the loop closed.
- **//:** Mark the exact point in the existing response where the pupil self-edits.
- **?:** Use Read it back; pupil reads, hears or indicates the highlighted sentence and checks their claim.

**Loop:** NS+ → pupil responds in their own mode → adult listens/looks and acts as Audience → R, normally revisited next lesson. A feedback mark alone is not R.

**Pathway expectation:** Pathways: high support, VF/WS · Build: mix of WS and I, can explain feedback · Grow: mostly independent, self-editing, NS and R · Launch: independent, self-assessing.

**Possible EHCP broad-area tag if an actual relevant behaviour is observed:** communication & interaction; cognition & learning. An observable example is locating a source line for “What should a reply identify?” and communicating its meaning with the support level noted. This is not an invented outcome or proof of one.

**TA prompts, least first (stop and fade when the pupil acts):**
1. “Which line might help with the first question?”
2. “Where does the page use the word visitor?”
3. “Can you point to the sentence that could answer ‘What should not be assumed?’?”

**Stretch:** How would you avoid presenting one visitor’s answer as everyone’s view?

**Way in:** Use a published source card and ask “What does this organisation say?”

**Image brief:** A source card with question marks: “What happens?”, “What does it mean?”, “Who says so?” Add only a licensed or original image and the matching Widgit symbols if the poster is landed.
