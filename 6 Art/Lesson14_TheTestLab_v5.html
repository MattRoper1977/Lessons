Bridge

The idea is locked 🎯 — now we test how to MAKE it 🧪

Art like a scientist: keep the drawing the SAME, change ONE variable at a time. First the media, then the background. The tests decide — not the guess.

🎨 Variable 1: media

Pencil tone · coloured pencil · fine liner + wash · oil pastel. Same section of your idea, four times.

🖼️ Variable 2: background

Plain white · tonal gradient · flat colour · textured/collage. The background changes the mood of the SAME image.

Arrival Task — Retrieval Quiz (Do Now)

Answer from memory. Media and the language of testing.

1) What does media mean in art?

The materials used to make artwork (pencil, paint, pastel…).

2) What does mixed media mean?

Using more than one material in the same artwork.

3) What was your final idea? One sentence.

Personal — the surreal eye idea from last lesson.

4) Which artist did your idea borrow from?

Magritte, Dalí or Höch.

1) In a fair test, how many things change at once?

One — everything else stays the same.

2) Which of these is a drawing media (not a technique)?

Media = the material (pencil, coloured pencil, fine liner, oil pastel). Hatching is a technique.

3) Two ways to make a colour lighter?

Add water (paint) or add white; press lighter with pencils.

4) What is hatching?

A mark-making technique using layers of parallel lines.

1) Why test one section, not redraw the whole idea four times?

It is faster and fairer — the drawing stays identical, so only the media differs.

2) How can a background change the mood of the same image?

Colour and texture set atmosphere — a dark gradient feels ominous; white feels clinical and calm.

3) What might oil pastel do BADLY that fine liner does well?

Fine detail — pastel is bold and soft-edged; liner holds crisp precise lines.

4) What evidence should each test box carry?

An annotation: what the media did well, what it did badly, verdict.

I Do: The Fair Test Page 🔬

One page, four boxes, one rule: only the media changes. Reveal the setup step by step.
Same section, four times — only the media changes.
Step 0 of 4

1️⃣ Divide the page

Fold or rule your page into four boxes. Title it: Media Tests.

2️⃣ Repeat the section

Draw the SAME section of your final idea in each box — trace or copy it, keep it identical.

3️⃣ One media per box

Work each box in a different media. Push each one to do its best work.

4️⃣ Verdict under each box

One line: what it did well, what it did badly. Circle the winner.

Testing is four different drawings — it is the SAME drawing four times. Change the drawing and the test proves nothing.

Key distinctions

Fair test = one variable changes, everything else identical. Media = the material; technique = how you use it. A losing test is still evidence — it tells you what to avoid.

Self-quiz — cover the answers, write, then check

  1. In a fair test, how many things change? — One.
  2. Fine liner's superpower? — Crisp, precise detail.
  3. Which background gives Dalí-style drama? — A tonal gradient.

Common mark-losers

Four different drawings (not a fair test) · boxes with no verdicts · choosing a winner with no "because" · treating a failed test as wasted work instead of evidence.

Memory hooks

"Same drawing, different clothes." · "Every box gets a verdict." · "Losing tests still teach."

Scaffolding – Foundation

Order: 4 boxes → same section in each → one media per box → verdicts → strips.

Verdict starters: "Best at ______. Worst at ______."

Trace your section to keep it identical — tracing is allowed in a fair test!

Scaffolding – Middle

Push each media to its superpower: pencil = full tonal range; liner = hatching + detail; pastel = bold blends; coloured pencil = layered depth.

Pick your two background strips to CONTRAST (e.g. white vs gradient) — contrast makes the choice obvious.

The final sentence needs both a "because" and an "I learnt that".

Scaffolding – Higher

Add a fifth, mixed-media test: liner detail over a wash, or pastel background under pencil. Note what the combination unlocks.

Judge backgrounds by MOOD, not prettiness: which one serves your surreal atmosphere?

Reference an artist in your verdicts ("the flat white reads Magritte-calm") — free analysis marks.
