Portfolio Studio run sheet

A minute-by-minute script that keeps the slot optional, bounded and pupil-owned.

Print
STATUS: PROPOSED — not in use; run deferred behind the recorded two-part trigger. These documents ship for evaluation only. The run waits on both: (a) the late-September three-week check run and its outcome recorded, and (b) Pass LL-J delivered and its specimens read by Matt (_close/OPEN_ITEMS.md #24). Then it becomes its own pass with its own brief. Nothing here is authorised for use with pupils.
0–2 · ARRIVE. “Choose: ready, one action, no upload, private or pass.” Regulate before opening files.
2–4 · OPTIONAL DAY-CLOSE. GROW/LAUNCH pupils may read existing line, work and existing next step. Ask “What do these show together?” Nothing marked. BUILD unchanged.
4–7 · SELECT. “Which one item best shows what you did or decided?” Delete/ignore duplicates and poor captures.
7–10 · MEANING. Pupil says/points/writes. Scribe exact words. Add date/title/exact criterion only if supplied.
10–12 · CHECK. Existing item? Needed? Safe? Approved? Authorship/status honest?
12–14 · PLACE. Approved portfolio/queue, return to subject, or no upload. Never raise status.
14–15 · REPORT AND CLEAR. Show pupil location/state/owner. Delete temporary copies from device/downloads.

Scripts

Useful

  • “Which bit is yours?”
  • “What does it show?”
  • “Do you want this shared, private or not used?”
  • “This stays candidate evidence until the assessor checks it.”
  • “No upload is fine.”

Do not say

  • “We need something from everyone.”
  • “Let me make that sound better.”
  • “I’ll sign it off.”
  • “We can recreate what happened.”
  • “Catch it up tomorrow.”

Stop cards

Safeguarding: stop, listen, use DSL procedure; nothing goes in ordinary evidence.
Real personal documents: stop; use fictional/redacted practice artefacts.
Missing authentic event: return to subject for a real future opportunity.
Unclear criterion or state: mark “not yet mapped” and return to owner.
