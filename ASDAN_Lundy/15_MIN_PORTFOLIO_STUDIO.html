Two lanes, one boundary: the optional day-close reads existing work; the curation lane may place one existing item. Neither lane creates a second assessment or a backlog.

Minute-by-minute

0–2 · ARRIVE

Regulate. Choose Ready / Needs one action / No upload / Private / Pass.

2–4 · OPTIONAL READ

GROW/LAUNCH may read existing line + work + existing next step. BUILD does not need a written line. Nothing recorded.

4–7 · SELECT

One strongest existing item. Remove duplicates, blur and irrelevant material.

7–10 · MEANING

Pupil says/points/writes what it shows. Add only exact words and missing metadata.

10–12 · CHECK

Criterion/state, authorship/support, safety, permission and owner. Assessor owns sufficiency.

12–15 · PLACE AND REPORT

Approved portfolio/queue, return to subject or no upload. Show status/location. Clear temporary copies.
