Autumn 2 · Fair rock tests

I can spot an unfair step in a rock test and fix it so both rocks are treated the same.

Fair or unfair

A fair test changes only one thing. Everything else stays the same. If two things change, the test is unfair.

Spot the mistake

Read what was done to both rocks. Find the step that is not the same, such as the drops, the rubs or the start.

Fix the test

Change the bad step so both rocks get the same. Both rocks start dry and get the same drops.

Compare fair results

Only compare results from a fair test. Water stays on top of slate. Water soaks into chalk.

Why it matters

An unfair test can give a wrong answer. We can trust a result only when the test is fair.

Putting it together

Spot the unfair step, fix it, then use the fair result to pick the best rock for the job.

Model steps

  1. Read what was done to both rocks.
  2. Spot what did not stay the same.
  3. Change that step so both match.

Fair or unfair

A fair test changes only one thing. Everything else stays the same. If two things change, the test is unfair.

An unfair test can give a wrong answer. We can trust a result only when the test is fair.
