Stage 1 · Opening

Calculating magnification and unit conversions

Learning intention: Calculate magnification, image size and actual size using the magnification equation and convert accurately between millimetres (mm) and micrometres (µm).

Today I can

  • I can state and rearrange the magnification equation (Magnification = Image size ÷ Actual size).
  • I can convert between millimetres (mm) and micrometres (µm) using ×1000 and ÷1000 before dividing.
  • I can set out a four-line calculation and record lens, image and actual sizes in a structured data table.

Work in your book first. Point, speak, sign, draw, type, write or direct an adult. You may pass.

Model clue: Three-panel model: magnification formula triangle (I = A × M), unit conversion bridge (1 mm = 1000 µm), and 4-line working.

2. Convert 36 mm into micrometres (µm), and convert 90 µm into millimetres (mm).

Help with this question

Use ×1000 and ÷1000.

3. Why does a magnification calculation go wrong if image size is in mm and actual size is in µm?

Help with this question

Both lengths must be in the same unit before dividing.

Check: Because you are dividing two different units; one length is 1000 times larger per unit than the other.

4. Look at Panel 3. Why does the answer ×400 have no mm or µm unit?

Help with this question

mm ÷ mm cancels.

Check: Magnification is a ratio of two lengths in the same unit, so the length units cancel out.

Aspire route

1. Convert 0.05 mm into micrometres (µm), and convert 250 nm into micrometres (µm) given 1 µm = 1000 nm.

Help with this question

Each step down the metric scale (mm -> µm -> nm) multiplies by 1000.

Check: 0.05 mm × 1000 = 50 µm; 250 nm ÷ 1000 = 0.25 µm.

2. A student claims "50 mm ÷ 50 µm = ×1 because 50 ÷ 50 = 1." Spot the error and calculate the true magnification.

Help with this question

Convert 50 mm to µm first.

Check: The units do not match. 50 mm = 50,000 µm, so 50,000 µm ÷ 50 µm = ×1000.

3. Rearrange I = A × M to make (a) A the subject and (b) I the subject, and state the unit of each when I is measured in µm.

Help with this question

Cover the unknown in the triangle.

Check: (a) A = I ÷ M (in µm); (b) I = A × M (in µm).

4. An image is 45 mm wide at ×900 magnification. Calculate the actual size in µm.

Help with this question

Convert mm to µm before or after dividing by 900.

Check: 45 mm = 45,000 µm; 45,000 ÷ 900 = 50 µm (or 45 ÷ 900 = 0.05 mm = 50 µm).

Stage 3 · Starter

Starter · 4-beat model and retrieval

Whiteboard 4-beat sequence

Beat 1: Beat 1 · Identify the quantities: write down I (image size), A (actual size) and M (magnification).
Beat 2: Beat 2 · Match the units: convert mm to µm (×1000) so both lengths share the exact same unit.
Beat 3: Beat 3 · Substitute and calculate: divide or multiply using the formula triangle (M = I ÷ A or A = I ÷ M).
Beat 4: Beat 4 · Check unit and plausibility: magnification has a × sign and NO length unit; actual cell size needs mm or µm.

Ready: step 0 of 4

Class fingers or thumbs vote

An image of a cell is 30 mm across, and the actual cell is 0.15 mm across. What is the magnification?

Hold up 1, 2, 3 or 4 fingers (or point), then tap to check.

Retrieval 1: How do you convert millimetres (mm) into micrometres (µm)?

Clue

1 mm = 1000 µm.

Answer: Multiply by 1000 (×1000).

Retrieval 2: How do you convert micrometres (µm) back into millimetres (mm)?

Clue

1000 µm = 1 mm.

Answer: Divide by 1000 (÷1000).

Retrieval 3: If you know the image size (I) and the magnification (M), how do you calculate the actual size (A)?

Clue

Cover A in the formula triangle.

Answer: Actual size = Image size ÷ Magnification (A = I ÷ M).

Stage 4 · I do 1

I do 1 · Calculating magnification when units already match

I do 1 · Calculating magnification when units already match

Step 1: Write the equation first: Magnification = Image size ÷ Actual size (M = I ÷ A).

  1. Step 1: Write the equation first: Magnification = Image size ÷ Actual size (M = I ÷ A).
  2. Step 2: Check the units of both lengths: Image size = 40 mm and Actual size = 0.10 mm (both are in mm, so no conversion is needed).
  3. Step 3: Substitute the numbers into the equation: Magnification = 40 ÷ 0.10 = 400.
  4. Step 4: Write the final answer with a multiplication sign and no length unit: ×400 (never 400 mm).

Worked example 1

Worked example 1 (Matched units): A photograph of a cheek cell measures 40 mm across. The actual cell is 0.10 mm across. Line 1 (Equation): Magnification = Image size ÷ Actual size. Line 2 (Units): Both values are in mm. Line 3 (Substitution): Magnification = 40 ÷ 0.10. Line 4 (Answer): ×400. Common mistake to avoid: never write "400 mm" for magnification, because the length units cancel out.

Stage 6 · I do 2

I do 2 · Converting mixed units (mm and µm) and rearranging for actual size

I do 2 · Converting mixed units (mm and µm) and rearranging for actual size

Step 1: Spot mixed units before touching the calculator: e.g. Image size = 50 mm, Actual size = 50 µm.

  1. Step 1: Spot mixed units before touching the calculator: e.g. Image size = 50 mm, Actual size = 50 µm.
  2. Step 2: Convert the larger unit (mm) into the smaller unit (µm) by multiplying by 1000: 50 mm × 1000 = 50,000 µm.
  3. Step 3: Substitute matched units into M = I ÷ A: Magnification = 50,000 µm ÷ 50 µm = ×1000.
  4. Step 4: When finding Actual size (A = I ÷ M), convert I into µm first so your answer comes out directly in µm.

Worked example 2

Worked example 2 (Mixed units + rearrangement): A student measures an onion cell image as 45 mm wide at a total magnification of ×900. Find the actual width of the cell in micrometres (µm). Line 1 (Equation): Actual size = Image size ÷ Magnification. Line 2 (Unit conversion): 45 mm × 1000 = 45,000 µm. Line 3 (Substitution): Actual size = 45,000 µm ÷ 900. Line 4 (Answer): 50 µm.

Supported exit ticket

1. Write the magnification equation linking magnification, image size and actual size.

Expected point

Magnification = Image size ÷ Actual size.

2. Does magnification have a length unit (such as mm or µm)?

Expected point

No — it is written with a × symbol (e.g. ×400).

Independent exit ticket

1. A cell is 0.2 mm wide and its image is 60 mm wide. Calculate the magnification.

Expected point

60 ÷ 0.2 = ×300.

2. Rearrange the magnification equation to make actual size the subject.

Expected point

Actual size = Image size ÷ Magnification.

Aspire exit ticket

1. An image is 45 mm wide at ×900 magnification. Calculate the actual size in µm.

Expected point

45 mm = 45,000 µm; 45,000 ÷ 900 = 50 µm.

2. Explain why mixed mm and µm units must be converted before dividing.

Expected point

Because 1 mm is 1000 times larger than 1 µm; dividing without converting makes the answer out by a factor of 1000.
