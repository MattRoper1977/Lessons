Independent

1. Explain how two new nuclei get matching chromosome sets. [4 marks]

  1. DNA is copied before mitosis (1 mark)
  2. The copies are identical, so the sets match (1 mark)
  3. The copies separate during mitosis (1 mark)
  4. Each new nucleus gets one matching set (1 mark)

2. Show why the whole DNA molecule should not be labelled as one gene. [4 marks]

  1. A gene is one section of DNA (1 mark)
  2. The DNA molecule is long and has many genes (1 mark)
  3. Each gene carries a different instruction (1 mark)
  4. The label marks a bracketed region, not the whole line (1 mark)

3. Calculate the aa chance for Aa × aa and explain why four actual offspring might have only one aa. [3 marks]

  1. The possible pairs are Aa and aa (1 mark)
  2. Two of four squares are aa, so the chance is 1 in 2 (1 mark)
  3. Probability is a chance for each offspring, so a group of four can differ (1 mark)

4. Mark your answer to question 1 with the scheme. Credit each point you can find in it and write one precise next step. [4 marks]

  1. Credit only the scheme points written in the answer (1 mark)
  2. Leave an unwritten point uncredited (1 mark)
  3. The next step names one missing idea (1 mark)
  4. The original answer stays visible (1 mark)

5. Try your next step on a fresh example: improve “DNA is copied first. The cell splits.” so that it explains how both nuclei get matching sets. [3 marks]

  1. Matching sets separate is added (1 mark)
  2. It comes before the cell splits (1 mark)
  3. Each new nucleus gets one set, so the cells match (1 mark)

Aspire

1. Correct the claim “Mitosis copies the DNA and halves the chromosome sets”. [4 marks]

  1. DNA is copied before mitosis, not by mitosis (1 mark)
  2. Mitosis separates the matching sets (1 mark)
  3. It does not halve the chromosome number (1 mark)
  4. Each new nucleus has the same number as the parent (1 mark)

2. Defend a gene label and name one limit of a DNA line model. [4 marks]

  1. The label marks a region (1 mark)
  2. A gene is a section of DNA that carries an instruction (1 mark)
  3. A line omits scale and the sequence (1 mark)
  4. A line omits how DNA is packaged (1 mark)

3. Evaluate “Aa × aa gives exactly two aa offspring in any group of four”. [4 marks]

  1. Two of four squares in Aa × aa are aa (1 mark)
  2. The chance is 1 in 2 for each offspring (1 mark)
  3. A group of four can have any number of aa by chance (1 mark)
  4. “Expected two” is better than “exactly two” (1 mark)

4. Evaluate this self-marking: “I wrote about mitosis so I get all 3 marks.” Use the scheme to judge it. [4 marks]

  1. Marks are given for written scheme points (1 mark)
  2. Each point is checked separately (1 mark)
  3. A topic word is not a scheme point (1 mark)
  4. A missing point becomes the next step (1 mark)

5. Write a precise next step for the answer “A gene is the whole DNA line.” Explain why it is precise. [4 marks]

  1. Name one change: “a gene is a short section of the line” (1 mark)
  2. The change matches the error (1 mark)
  3. The step can be tried on a fresh example (1 mark)
  4. It is specific, unlike “try harder” (1 mark)

Accept scientifically equivalent wording. Award each distinct point once. The mark tariff is for the question, not a participation score. Keep the answer scheme staff-only during independent work.

You do routes

Independent is preferred: work in the book without answer-giving support. Supported uses a small prompt beside the same task. Choice uses limited options, matching or selecting and then a short scientific sentence, label or reason in the book. Aspire is the challenge for every route.

Mark scheme · one point per mark

Independent

1. Explain how two new nuclei get matching chromosome sets. [4 marks]

  1. DNA is copied before mitosis (1 mark)
  2. The copies are identical, so the sets match (1 mark)
  3. The copies separate during mitosis (1 mark)
  4. Each new nucleus gets one matching set (1 mark)

2. Show why the whole DNA molecule should not be labelled as one gene. [4 marks]

  1. A gene is one section of DNA (1 mark)
  2. The DNA molecule is long and has many genes (1 mark)
  3. Each gene carries a different instruction (1 mark)
  4. The label marks a bracketed region, not the whole line (1 mark)

3. Calculate the aa chance for Aa × aa and explain why four actual offspring might have only one aa. [3 marks]

  1. The possible pairs are Aa and aa (1 mark)
  2. Two of four squares are aa, so the chance is 1 in 2 (1 mark)
  3. Probability is a chance for each offspring, so a group of four can differ (1 mark)

4. Mark your answer to question 1 with the scheme. Credit each point you can find in it and write one precise next step. [4 marks]

  1. Credit only the scheme points written in the answer (1 mark)
  2. Leave an unwritten point uncredited (1 mark)
  3. The next step names one missing idea (1 mark)
  4. The original answer stays visible (1 mark)

5. Try your next step on a fresh example: improve “DNA is copied first. The cell splits.” so that it explains how both nuclei get matching sets. [3 marks]

  1. Matching sets separate is added (1 mark)
  2. It comes before the cell splits (1 mark)
  3. Each new nucleus gets one set, so the cells match (1 mark)

Aspire

1. Correct the claim “Mitosis copies the DNA and halves the chromosome sets”. [4 marks]

  1. DNA is copied before mitosis, not by mitosis (1 mark)
  2. Mitosis separates the matching sets (1 mark)
  3. It does not halve the chromosome number (1 mark)
  4. Each new nucleus has the same number as the parent (1 mark)

2. Defend a gene label and name one limit of a DNA line model. [4 marks]

  1. The label marks a region (1 mark)
  2. A gene is a section of DNA that carries an instruction (1 mark)
  3. A line omits scale and the sequence (1 mark)
  4. A line omits how DNA is packaged (1 mark)

3. Evaluate “Aa × aa gives exactly two aa offspring in any group of four”. [4 marks]

  1. Two of four squares in Aa × aa are aa (1 mark)
  2. The chance is 1 in 2 for each offspring (1 mark)
  3. A group of four can have any number of aa by chance (1 mark)
  4. “Expected two” is better than “exactly two” (1 mark)

4. Evaluate this self-marking: “I wrote about mitosis so I get all 3 marks.” Use the scheme to judge it. [4 marks]

  1. Marks are given for written scheme points (1 mark)
  2. Each point is checked separately (1 mark)
  3. A topic word is not a scheme point (1 mark)
  4. A missing point becomes the next step (1 mark)

5. Write a precise next step for the answer “A gene is the whole DNA line.” Explain why it is precise. [4 marks]

  1. Name one change: “a gene is a short section of the line” (1 mark)
  2. The change matches the error (1 mark)
  3. The step can be tried on a fresh example (1 mark)
  4. It is specific, unlike “try harder” (1 mark)

Accept scientifically equivalent wording. Award each distinct point once. The mark tariff is for the question, not a participation score. Keep the answer scheme staff-only during independent work.
