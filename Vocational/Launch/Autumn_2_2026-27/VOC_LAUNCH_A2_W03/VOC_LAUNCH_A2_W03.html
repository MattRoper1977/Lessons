Teacher and cover guidance

Watch (staff preview first): none suggested

Purpose and preparation

  • Following Instructions and Routines
  • I can follow a set of instructions in order.
  • I can describe a workplace routine.
  • I can check my work against the instructions.
  • Prepare: book, pencil, printed cards, word page and one task guide per pupil. Have an accessible seated option. No login or connection is needed.
  • This is one lesson. Suggested time: 40 minutes. Adjust for access; do not rush the practical checks.
  • Safety: The screen describes steps only. Any practical task is off screen, authorised and supervised. The adult checks the space, kit, water and task rules first. Use no hot, sharp, powered or chemical kit without the specific controls and training. Stop for spills or damaged kit. Dry card rehearsal remains available and is recorded as rehearsal.

Arrival and starter

  • Arrival - 4 minutes: Read the goal. Offer a quiet start and the usual aid. Show the picture without reading its labels. Invite the three recall answers in any mode. Keep the first-try count separate from later learning. A pass is welcome.
  • Starter - 4 minutes: Read the four case steps. Use the silent lights one at a time. Ask what comes next and why. Take the class vote; receive the reason before confirming the order.

Modelling and hinge

  • I do - 7 minutes: Reveal one task step at a time. Think aloud: The task is a paper model of a service tray. I read to the end before I place a card. The standard is one tray, two cups above it and a spoon to the right. I count two cups and check the spoon. This is rehearsal, not food work. Ask the hinge question before revealing the answer.
  • Hinge: The guide says two cups. You see one. What next?
  • Expected: Use the guide to find the missing part, then correct it.
  • If a response is wrong or absent, check access first. Model one example, offer two choices and retest with a changed case. Move on when each pupil can show the key check.

Team rehearsal and independent work

  • We do - 7 minutes: Human sequence: teams hold the four paper step cards. Agree the order by pointing or speaking. Seated pupils can direct a partner. The teacher moves around, asks for a reason and lets the team change one card. Scoring: 1 point for each card in the correct place; 1 point for spotting and fixing an error using the guide. All teams can earn points. Ask one pupil per team to explain a check. If pupils need more help, return to one modelled example and retest privately.
  • Independent - 14 minutes: Offer the three routes as choices of support and depth. Read the book line. Keep the optional making choice optional. Observe each pupil, fade one prompt when secure and record actual help.
  • In your book, keep your card model or draw it. Number the steps. Record one check and any help used.

Review exit and evidence

  • Exit - 4 minutes: Use the three exit questions. Ask for a success and a next step. Read back any scribed words for the pupil to confirm. Use the response to choose the next support or task.
  • Next we agree clear roles while using a shared task guide.
  • Evidence: record the individual action, response mode, task standard and exact support. A quiz score, group product or paper simulation does not prove practical competence. Use the unit award only where authorised and supported by actual evidence.
  • Feedback: receive the pupil response, give one next step and invite an edit in the same colour, on the same page or usual mode. Keep the original response visible.
  • Prompt ladder: wait; point to the guide; ask a short question; rephrase; give two choices; model the first step; return the task to the pupil.

Following Instructions and Routines

Misconceptions

Checking means asking whether it looks nice. Correction: Count the named parts and compare their places with the guide.

You should guess an unclear step. Correction: Stop and ask before going on.

An error means the whole task failed. Correction: Spotting and fixing an error is a useful work skill.

Accept a different defensible example if the pupil links it to the task. Record a pass as a pass; never guess an answer or outcome.
