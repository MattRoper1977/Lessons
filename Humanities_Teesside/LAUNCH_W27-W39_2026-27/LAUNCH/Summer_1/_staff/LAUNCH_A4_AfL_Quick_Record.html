W1 LAUNCH_SU1_W01

  1. Q1. What does ppm label in a CO₂ source? ✓ Concentration ↳ Temperature
  2. Q2. Can a trend alone prove a single cause? ✓ No ↳ Yes
  3. Q3. What must a data claim include? ✓ Value or trend, unit and source ↳ Only an opinion
  4. Q4. What is resource use linked to in this enquiry? ✓ Emissions and climate change ↳ Map grid references
  5. Q5. If axes have different units, can values be swapped? ✓ No ↳ Yes
  6. Q6. What is a limit of one data series? ✓ It may not isolate all causes ↳ It proves every impact

W2 LAUNCH_SU1_W02

  1. Q1. Does cutting emissions address causes or impacts? ✓ Causes ↳ Impacts only
  2. Q2. Does a flood barrier mainly address causes or impacts? ✓ Impacts ↳ Causes only
  3. Q3. What must a response evaluation include? ✓ Benefit and limitation ↳ Only a slogan
  4. Q4. Can one response solve every climate risk? ✓ No ↳ Yes
  5. Q5. What should alternatives be judged against? ✓ Same criterion/evidence ↳ Different standards
  6. Q6. If an action is costly, is it automatically useless? ✓ No; weigh cost against benefit ↳ Yes

W3 LAUNCH_SU1_W03

  1. Q1. What makes a decision reasoned? ✓ Criteria plus evidence ↳ Loudest preference
  2. Q2. Why apply the same criteria to both options? ✓ Fair comparison ↳ To make them identical
  3. Q3. What does a limitation do? ✓ Shows where evidence is uncertain ↳ Cancels all evidence
  4. Q4. If priorities change, can the decision change? ✓ Yes, explain how ↳ No
  5. Q5. What should a partner challenge target? ✓ Evidence or criterion ↳ The person
  6. Q6. What belongs in a final recommendation? ✓ Choice, reason and trade-off ↳ Choice only

W4 LAUNCH_SU1_W04

  1. Q1. What does a campaign action need? ✓ Specific audience and doable action ↳ A vague slogan
  2. Q2. Can a draft claim an unmeasured result? ✓ No ↳ Yes
  3. Q3. Why name the audience? ✓ To choose suitable language/action ↳ To add decoration
  4. Q4. What is a fair check of a draft? ✓ Test clarity and evidence ↳ Count emojis
  5. Q5. If an image is used, what helps access? ✓ Useful alternative text ↳ No description
  6. Q6. What should happen to an unsupported number? ✓ Remove or source it ↳ Make it larger

W5 LAUNCH_SU1_W05

  1. Q1. What does before/after difference mean? ✓ After minus before with direction stated ↳ Add the two values
  2. Q2. Can invented practice data be reported as a real local result? ✓ No ↳ Yes
  3. Q3. What makes a role contribution checkable? ✓ Named task and evidence ↳ A vague claim
  4. Q4. Why agree roles before the trial? ✓ Clear and fair contribution ↳ To avoid checking
  5. Q5. What is needed to claim an action caused a change? ✓ A fair comparison and limits ↳ Any two numbers
  6. Q6. Which label belongs on simulated figures? ✓ Practice/simulated ↳ Observed locally

W6 LAUNCH_SU1_W06

  1. Q1. What must support a recommendation? ✓ Criterion, source and limitation ↳ Opinion alone
  2. Q2. If two sources disagree, what next? ✓ Discuss reliability and uncertainty ↳ Hide one
  3. Q3. What does a score need beside it? ✓ An evidence note ↳ A decorative icon
  4. Q4. Can a provisional decision be revised? ✓ Yes with new evidence ↳ Never
  5. Q5. What makes a report evaluative? ✓ Weighs trade-offs ↳ Lists facts only
  6. Q6. How should a challenge be answered? ✓ With criterion and evidence ↳ By repeating the claim
