# LAUNCH_SU1_W01 · TA deployment brief

## EEF five-layer scaffolding key

**Self-scaffold → prompt → clue → model → correct.** Move down only when the pupil can't go on; move back up as soon as they can. Start by waiting, checking the pupil’s own attempt and using the existing visual, communication or reading aid. An access aid is not a content answer.

1. **Self-scaffold — watch for:** Distinguishes a concentration value in ppm from a temperature reading. Let the pupil check the source, key, diagram or own work before speaking.
2. **Prompt — two open questions:** “What are the axes measuring?” “Which value and unit support your claim?” Pause after each; accept point, sign, AAC, speech or writing.
3. **Clue — two narrowed questions:** “Which plotted value or trend supports the claim?” “What source or missing variable limits the inference?” Give one clue at a time and then step back.
4. **Model — one step only:** Show one first step: Read each axis and unit aloud; describe one change before explaining it. Then the pupil tries the next matching move with the source in view.
5. **Correct — one direct fact and when:** If the pupil still cannot continue after that model, give only “Concentration” for “What does ppm label in a CO₂ source?”. Then ask for a fresh application, record the level used and fade back toward self-scaffolding.

**Objective:** Explain resource use and climate change using online data.
