Sharing something special

Original captioned teaching model made for this pack. It demonstrates the supplied reasoning; it is not historical footage, survivor testimony or a documentary. The full transcript and factual source credits are included.

Question: What can make an object special?

Evidence: B Object card: a key ring: Fictional case: Lee has a key ring from a seaside trip. It reminds Lee of a day out with an aunt. C Object card: prayer beads: Some people use beads to help them pray or reflect. For them the beads link to belief.

Think aloud: A person, a memory, a belief or a place.

Check: Do you have to share a real object from home? No. A photo, drawing or object card is a complete response.
