Grid references and navigation

Learning goal: Use an atlas and grid references to describe location.

Remember

What is the park’s four-figure reference on the practice grid? 1122.

What does a four-figure reference identify? A grid square, not an exact point.

How to show your learning

Use the supplied grid to find three places.

Along the corridor, then up the stairs: easting ___, northing ___.

Evidence matters

Fictional cases are teaching examples. Historical, geographical and religious claims use the named sources. A model video demonstrates a method.

You can respond by speaking, pointing, drawing, typing or writing. A fictional personal example is welcome.
