Our school and local features

Learning goal

Name and locate my school and local features.

How can we help a visitor find a place?

I can name my school, find local features and show where one place is.

40 minutes, with flexible pauses. Point, speak, draw, type or write. A fictional example is welcome.

Teacher brief

Teacher notes and answers

Teacher card: staff only

Our school and local features / BUILD_SU1_W01

Outcome: Name and locate my school and local features.

Assessment: F: map check plus one independent location question.

Teaching sequence: Model a simple map key; match symbols to places. Locate familiar features and describe a route using near/far/left/right.

Preparation

Use the invented plan for practice. Supply a checked plan of the school and nearby features for the local task. No home addresses or other pupil personal details are needed.

Choose the independent route. Print the matching page and exit ticket. Check the real-school locations before teaching. Keep pupil responses private.

Forty-minute route

Opening 0; arrival 4; starter 3; model 6; shared 7; check 2; independent 12; review 3; exit 3.

Feedback and next attempts

  1. Arrival: if the key is unfamiliar, offer two picture choices. Recheck with a different symbol.
  2. Starter: if a pupil guesses, ask them to point to one clue. Hear the new explanation.
  3. We do: if a match is secure, ask for a reason. If not, compare two places and try again.
  4. Check: if left/right is confused, keep the plan still and trace from S to L. Ask the pupil to repair the note.
  5. Independent: if ready, fade the content prompt. Let the pupil locate a new feature using their usual access support.
  6. Exit: use the independent response to choose the next task: another feature, a new route or more key practice.

Clue hunt answers

  1. I want to borrow a book. L: Library. The open-book picture and L identify the library.
  2. I need a place to wait for a bus. B: Bus stop. The bus picture and B identify the bus stop.
  3. I want an open green space. P: Park. The tree picture and P identify the park.
  4. I have an appointment with a nurse. C: Clinic. The cross picture and C identify the clinic.

Visitor note

Change left to right. Keep the plan the same way up.

Independent task and exit

Answers depend on the teacher-supplied plan. Check the school name, symbol and location against it. Accept accurate pointing, speech, drawing or writing. Ask one new location question without a content prompt. Record the pupil’s own response.

Access

Give one instruction at a time. Offer pointing, speech, drawing, typing or writing. Begin with two choices. Fade the prompt before the final location question.

Offer a quiet first attempt and a choice of response mode. Allow passing and an agreed pause. Name the next small step when the learner returns.
