W1 BUILD_SU1_W01

  1. Q1. On the Townside plan, what does S mark? ✓ School ↳ Shop
  2. Q2. Which symbol marks the library? ✓ L / open book ↳ P / tree
  3. Q3. From S, which square is one right? ✓ Library ↳ Bus stop
  4. Q4. What does a map key tell us? ✓ What symbols mean ↳ How fast to walk
  5. Q5. What do you check before naming a real local feature? ✓ The checked local plan or observation ↳ The invented Townside plan
  6. Q6. If a visitor wants a book, where do you point? ✓ Library ↳ School

W2 BUILD_SU1_W02

  1. Q1. Where must route directions begin? ✓ At the named start ↳ At any landmark
  2. Q2. What is the first move from S to L on Townside? ✓ One square right ↳ One square down
  3. Q3. What does a route checker do? ✓ Follows each move on the plan ↳ Guesses the end
  4. Q4. If a direction is unclear, what helps? ✓ Ask which start or turn ↳ Keep guessing
  5. Q5. Which instruction is more exact: 'over there' or 'one square right'? ✓ One square right ↳ Over there
  6. Q6. When does a route reach the right place? ✓ When the traced endpoint matches the target ↳ When it sounds familiar

W3 BUILD_SU1_W03

  1. Q1. What do you use for a fair place comparison? ✓ The same feature for both places ↳ Different features for each
  2. Q2. What belongs in the 'both' column? ✓ A feature shown in each source ↳ A feature from one source
  3. Q3. Can one photo prove what every street is like? ✓ No, only the view shown ↳ Yes, every street
  4. Q4. Which sentence compares? ✓ Place A has a park; B has a harbour ↳ A has a park
  5. Q5. What should you do when a feature is not visible? ✓ Say the source does not show it ↳ Say it does not exist
  6. Q6. What makes a difference claim checkable? ✓ A detail from both sources ↳ A guess

W4 BUILD_SU1_W04

  1. Q1. What comes before making a fieldwork tally? ✓ Agree the feature and area ↳ Write a conclusion
  2. Q2. How many tally marks for three observed benches? ✓ Three ↳ One
  3. Q3. What must be written beside a count? ✓ Feature and area ↳ Only the total
  4. Q4. Does an indoor practice count prove what is outside? ✓ No ↳ Yes
  5. Q5. If the group counts the same item twice, what next? ✓ Recheck and correct tally ↳ Keep both marks
  6. Q6. What can you do if you need a pause outside? ✓ Use agreed pause/help signal ↳ Leave without telling anyone

W5 BUILD_SU1_W05

  1. Q1. Which is land: Africa or Atlantic Ocean? ✓ Africa ↳ Atlantic Ocean
  2. Q2. Which is water: Pacific Ocean or Europe? ✓ Pacific Ocean ↳ Europe
  3. Q3. What helps locate a named continent? ✓ Label and map key ↳ Colour alone
  4. Q4. Is the UK a continent? ✓ No ↳ Yes
  5. Q5. What does an ocean label point to? ✓ A large body of water ↳ Any blue mark
  6. Q6. What can a world map show that a school plan cannot? ✓ Continents and oceans ↳ Desk locations

W6 BUILD_SU1_W06

  1. Q1. What should a class-map symbol stand for? ✓ An observed local feature ↳ A guessed feature
  2. Q2. Where does a counted feature go? ✓ At its checked map position ↳ Anywhere with space
  3. Q3. Why include a key? ✓ To explain symbols ↳ To make the map longer
  4. Q4. What if partners use different symbols for one feature? ✓ Agree one and label it ↳ Leave both unexplained
  5. Q5. Does a practice plan prove the feature is in the grounds? ✓ No; check local evidence ↳ Yes
  6. Q6. How can a pupil show where a symbol belongs? ✓ Point, place or direct a partner ↳ Only write a paragraph
