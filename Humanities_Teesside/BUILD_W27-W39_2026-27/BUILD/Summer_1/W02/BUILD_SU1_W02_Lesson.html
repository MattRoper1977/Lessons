I do · a worked method

Choose help or a further challenge

Use a counter and one direction at a time. Choose from two destinations.

Trace each move, then name the destination. Swap partner roles.

Give a different route to the same place. Explain how you checked it.

Read all model steps

Question: Where does this route finish? Start at S. Move right, then down.

Evidence: The key names S as school. One move right reaches L, the library.

Explain: One move down from L reaches X, the crossing. X is the destination.

Check: Trace S to L to X again. Two moves, no diagonal jump.

Independent

Independent application

Use the checked familiar-place plan.

Choose one route and one response mode. Keep the same learning goal.

Supported task

  1. Find the start on the familiar-place plan with an adult.
  2. Follow one short route, with directions read aloud.
  3. Mark or point to the destination yourself.

Use a counter. Hear one direction at a time. Point or say: I finish at ___.

Try a new destination with the content prompt removed.

Standard task

  1. Mark a start on the familiar-place plan.
  2. Build a short route for a partner. Swap roles.
  3. Follow the new route and mark its destination independently.

Use the key and directions on the checked plan. Say: From ___, go ___ to ___.

Check one unclear instruction and rewrite or say it more clearly.

Stretch task

  1. Give a precise route on the familiar-place plan.
  2. Ask a partner to test it. Repair any unclear instruction.
  3. Follow a fresh route and mark its destination independently.
  4. Explain one check using a feature on the plan.

Keep the starting point and the plan orientation clear.

Find another valid route if the paths allow it. Explain the difference.

Teacher card

Routes on a familiar plan

Outcome: Use a simple map or plan of a familiar place.

Assessment: F: map check plus independent route/location response.

Teaching: Follow a model route; build a route for a partner, then independently mark its destination. Use a simplified map and clearly defined role.

Preparation

Townside is an invented practice plan. Use the editable familiar-place plan sheet to add a checked school plan before teaching. Keep the plan the same way up. Left and right mean on the page; pupils do not turn their bodies. On Townside, move only to an adjacent square, never diagonally.

40 minute route

Opening 0; Arrival 4; Starter 3; I do 6; We do 7; Check 2; Independent 12; Review 3; Exit 3.

Access and feedback

One instruction at a time. Point, speak, draw, type or write. Use the supported route for a smaller choice set. Fade content prompts before the independent check.

Offer a seated counter route and a quiet partner or adult. Give thinking time, allow passing, and agree a small first move after a pause.

Keep reading and communication support. Fade route-content prompts for the final response. Record the start, route, destination and support used.

Worked model

  1. Question: Where does this route finish? Start at S. Move right, then down.
  2. Evidence: The key names S as school. One move right reaches L, the library.
  3. Explain: One move down from L reaches X, the crossing. X is the destination.
  4. Check: Trace S to L to X again. Two moves, no diagonal jump.

Arrival answers

Supported

  1. S is in the top-left square.
  2. Right is towards the key.
  3. B, the bus stop.
  4. A destination is the place a route ends.

Standard

  1. S means school.
  2. L, the library.
  3. X, the crossing.
  4. The place a route ends.

Stretch

  1. L, the library.
  2. F, the flats.
  3. Different starts can give different destinations.
  4. Right then down, or down then right.

Shared activity answers

  1. Start S. Right, then down. X: Crossing. S to L to X is right, then down.
  2. Start S. Down, then down. T: Sports court. S to B to T is two moves down.
  3. Start P. Down, then left. X: Crossing. P to H to X is down, then left.
  4. Start F. Left, then up. X: Crossing. F to C to X is left, then up.
  5. Start X. Left, then down. T: Sports court. X to B to T is left, then down.

Check answer

The destination is X, the crossing. H needs one more move right. Trace S to L to X.

Independent and exit answers

Answers depend on the checked local source set. Keep reading and communication support. Fade route-content prompts for the final response. Record the start, route, destination and support used.
