Routes on a familiar plan

Learning goal: Use a simple map or plan of a familiar place.

Words to use

WordMeaning
planA view from above showing where things are.
routeThe way from a start to a destination.
destinationThe place where a route ends.
keyA guide to the symbols on a map.

A method to use

  1. Find the start in the key.
  2. On Townside, move one square per direction. On a real plan, follow its marked paths.
  3. Mark the destination.
  4. Trace the route again to check.

Point, speak, draw, type or write. Use the key and check the evidence.

Practice plans are invented. Use your teacher’s checked local sources for the final task.
