Our class map

Learning goal: Record local features on a class map.

Words to use

WordMeaning
featureSomething in a place, such as a tree, path or bench.
symbolA small sign used to stand for something on a map.
keyA guide explaining the map’s symbols.
evidenceAn observation or checked source that supports a map entry.

A method to use

  1. Choose a feature supported by checked evidence.
  2. Find its position on the class plan.
  3. Add a clear symbol or label and key entry.
  4. Explain your contribution and check it.

Point, speak, draw, type or write. Check your evidence.

Use the class’s own checked plan and actual local observations. Keep an individual contribution record as well as the shared map.
