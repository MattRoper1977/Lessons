Teacher card

Staff only | BUILD_SU1_W06

Our class map

Outcome: Record local features on a class map.

Assessment: S: class map contribution plus individual evidence against unit criteria.

Teaching: Return to fieldwork photos and observations; model one map entry. Each learner adds accurate symbols or labels and explains a feature. Review map, comparison and world-location evidence from the unit.

Preparation

Reuse the class’s own checked plan from earlier local work. Before teaching, confirm its orientation, key and permitted area. Bring checked Week 4 observations and each learner’s earlier map, comparison and world-location work. Use existing photos of places only if suitable; no photographs of people or home addresses. If Week 4 used invented practice data, do not transfer those counts or locations to the real class map. Verify a real feature with an adult observation or checked school plan first. The supplied demonstration plan is practice only.

40 minute route

Opening 0; Arrival 4; Starter 3; I do 6; We do 7; Check 2; Independent 12; Review 3; Exit 3.

Access and feedback

Give one instruction at a time. Offer pointing, speech, drawing, typing or writing. Use a reduced choice set if needed. Keep communication support and fade content prompts before the individual check.

Offer a private rehearsal, a small paper contribution to place on the shared map and a choice of response mode. No personal disclosure is needed.

Summative: retain the class map contribution and the learner’s own explanation/support record. Review map skills, simple symbols, a comparison, an observation and a continent/ocean response against unit criteria. Use earlier work where valid; do not infer individual attainment from the shared product. If evidence is missing, record not yet evidenced and plan a short follow-up.

Shared activity answers

  1. The adult-checked plan and today’s observation agree: a bench is beside the tree. Add to map. The feature and position are verified. Add a clear symbol and key entry.
  2. A visitor thinks there may be a bin behind the hall, but nobody has checked. Check first. The position is uncertain. Confirm it with the checked plan or an adult observation.
  3. Someone suggests adding a pupil’s home address. Leave out. A home address is not needed for this school/local-features map.
  4. A practice tally from an invented area shows five trees. Leave out. Invented practice data is not evidence for our real local map.
  5. An old plan shows a bench, but it may have moved. Check first. Check its current position before adding it.

Check answer

No. The tally was invented practice data. Use the class’s checked plan and real observations to verify tree positions before adding them.

Independent and exit answers

Answers depend on the checked local source set. Summative: retain the class map contribution and the learner’s own explanation/support record. Review map skills, simple symbols, a comparison, an observation and a continent/ocean response against unit criteria. Use earlier work where valid; do not infer individual attainment from the shared product. If evidence is missing, record not yet evidenced and plan a short follow-up.

Actual map answers depend on the class’s checked plan and observations. Require a feature consistent with its source, an accurate position, an interpretable symbol/key, and the learner’s explanation. Accept spoken, pointed, drawn or written evidence. Practice-only work must be labelled and cannot stand in for a verified local-map contribution.
