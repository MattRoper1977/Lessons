Objective: Record local features on a class map.

- **VF** — After the I-do hinge or at Review, the adult gives verbal feedback about the actual response to “I can place a local feature where the observation shows it and explain its symbol in the key”.
- **WS** — In We-do, record actual scaffolded work on the ladder and the prompt level; access aids alone are identified separately.
- **I** — At Independent application (slide-7), mark only a pupil’s own independent content decision or explanation.
- **NS+** — At Review / Exit, name one specific next step from the hinge, work or exit evidence; leave blank if none given.
- **//** — At Review, mark the point where the pupil actually self-edits a response against feedback or the criterion.
- **?** — At Exit, press “Read it back (?)” and hear, see or receive the pupil’s read-back by their agreed mode.
- **R** — At the next lesson Arrival, receive the pupil’s response to the NS+ and engage with it; close the loop then, not when NS+ is first given.
- **E** — At Independent / Exit, capture only observed Job 2 evidence if it occurs: communication & interaction: Explains the meaning of the symbol added to the class map; cognition & learning: Places a feature using the checked local evidence; SEMH: Negotiates a symbol choice with a partner using an agreed turn-taking routine; sensory & physical: Positions a symbol with the usual accessible pointing or placement aid. Use the existing evidence record.
