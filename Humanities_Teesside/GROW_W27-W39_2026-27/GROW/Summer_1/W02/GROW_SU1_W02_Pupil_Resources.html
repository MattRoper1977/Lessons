A Practice grid method

The practice grid is an invented place. Read eastings across first, then northings up. Use the lines at the left and bottom of the square. Four figures identify a square, not an exact point.

Source: Authored practice grid; Ordnance Survey grid references guide

Limit: Its numbers are practice references, not full national-grid coordinates.

B Atlas view of the School

Fictional atlas example of the same practice place: the index entry School points to page A, square C2. Open that page and follow its page grid. The printed view and scale stay fixed until you choose a different map.

Source: Authored atlas evidence card for the supplied practice place

Limit: C2 is an atlas page locator. It is a different system from the four-figure practice grid.

C Digital view of the School

Fictional digital-map example of the same School: use its public place name in a search box, change zoom and switch relevant layers. These controls change what you see. Your teacher demonstrates equivalent controls on the school’s approved tool using a public place.

Source: Authored digital-map evidence card for the same practice place

Limit: No live map is embedded. The practice place is invented. Never search for a home address.

D A route between squares

On the practice grid, start at School. Move one square north to Library, then one square east to Hall. Trace each move and use the printed references. This is a map route, not an outdoor walking instruction.

Source: Authored practice grid

Limit: The grid does not show paths, entrances or a safe real-world route.
