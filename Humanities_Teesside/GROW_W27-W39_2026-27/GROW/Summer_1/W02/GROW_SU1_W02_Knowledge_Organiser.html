Use atlases grid references and digital maps.

Words to use

WordMeaning
atlasA collection of maps, often with an index
grid referenceNumbers or letters used to locate a map square
eastingA grid number read across the map first
northingA grid number read up the map second

Map reading method

Find the feature and its square.

Read the easting at the left, then the northing at the bottom.

Join the two pairs and check the printed reference.

Compare atlas index/page grid with digital search/zoom/layers.

Remember

Four figures identify a square. Atlas page locators use the atlas’s own system. Digital layers change the information shown. The teacher uses an approved tool and a public place. Never search for a home address.
