# GROW_SU1_W06 · TA deployment brief

## EEF five-layer scaffolding key

**Self-scaffold → prompt → clue → model → correct.** Move down only when the pupil can't go on; move back up as soon as they can. Start by waiting, checking the pupil’s own attempt and using the existing visual, communication or reading aid. An access aid is not a content answer.

1. **Self-scaffold — watch for:** Identifies a missing study section using the evidence checklist. Let the pupil check the source, key, diagram or own work before speaking.
2. **Prompt — two open questions:** “Which section of the evidence list is missing?” “Where is the original tally?” Pause after each; accept point, sign, AAC, speech or writing.
3. **Clue — two narrowed questions:** “Which value in the graph should equal the tally?” “What does the evidence list say is still missing?” Give one clue at a time and then step back.
4. **Model — one step only:** Show one first step: Start with the original count, then match that number on the graph and evidence list. Then the pupil tries the next matching move with the source in view.
5. **Correct — one direct fact and when:** If the pupil still cannot continue after that model, give only “The recorded tally total” for “Which fieldwork value must match the graph?”. Then ask for a fresh application, record the level used and fade back toward self-scaffolding.

**Objective:** Complete a fieldwork and locality study and bank UAS evidence.

| Stage | Position and role |
|---|---|
| Arrival / Starter | Sit at the side of the group with sight of access needs; quietly support the pupil using the agreed communication or reading aid. Observe the first unprompted attempt. |
| We do / We do 2 | Move beside the pair checking the model or source; alternate turns, point to the evidence and fade cues. Avoid becoming the pupil's answer-giver. |
