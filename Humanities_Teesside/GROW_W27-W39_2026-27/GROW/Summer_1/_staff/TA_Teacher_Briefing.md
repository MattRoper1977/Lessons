# Job 10 · TA / teacher briefing (Progress Schools staff-facing)

**10 minutes · review-only Job 9 routines · 36 Summer 1 Humanities / core Science ids**

Job 9 contains proposed drop-ins. No existing lesson has been edited or landed. Humanities stages are source-verified; Science stages are scheme-level proposals. Use LAUNCH Science W06 fragments during preparation, outside the live assessment.

## Run the briefing

| Time | Routine | Say / rehearse |
|---|---|---|
| 0:00–1:30 | Locate the sequence | A hinge after I-do; B ladder in We-do; C Exit. Science placements are proposals until the actual lesson is checked. |
| 1:30–3:00 | Hinge | Ask one question. Every pupil responds together by whiteboard, finger-vote, symbol card, thumbs or point. Scan responses before choosing the next move. |
| 3:00–4:30 | Challenge | Ask recall → explain → apply/evaluate. Everyone hears the top rung; use the blue way in and green stretch as needed. |
| 4:30–6:30 | TA scaffold | Wait for self-scaffolding, then prompt, clue, model one step, correct only if needed. Move down only when stuck; move back up as soon as possible. |
| 6:30–8:00 | Independent & codes | Agree adult coverage for the Independent stage and swap roles across the week. Record actual support or independence, not a planned code. |
| 8:00–10:00 | Exit handoff | Hear the four pupil-voice answers; cue Read it back (?). TA passes the prompt level reached and what was independent to the teacher. |

## The three visible moments

- **A · after I-do — hinge:** one question; all pupils respond at once. Teacher-only 10-second decision: **most right → move on · split → pair check · most wrong → re-teach the I-do step**. No automatic mark or saved response.
- **B · We-do — ladder:** recall → explain → apply/evaluate. **Everyone hears the top rung; scaffold the route, don't lower the rung.** Blue is the way in; green is the deeper stretch.
- **C · Exit — pupil voice:** point to the success line, ask the four questions below and use **Read it back (?)**. Accept spoken, signed, symbol/AAC, pointed, drawn, typed or written responses.

**Five-layer rule:** self-scaffold → prompt (open question) → clue (narrowed question) → model (one step, then pupil tries) → correct (one direct fact only when needed, then fresh attempt). **Move down only when the pupil cannot go on; move back up as soon as they can.** Note the deepest layer used and what the pupil then did independently.

**Teacher time:** At **Independent**, one adult works with supported pupils while the other holds the group; swap roles across the week. Agree names, position and handoff before teaching. Job 9 currently marks `TEACHER-TIME: NONE — flag` for all 36 ids because this exchange is not specified in the verified stages; this briefing is the rule to schedule, not evidence that it has happened.

## Feedback code map — write a code only when it happened

| Code | Meaning and when |
|---|---|
| **VF** | Verbal feedback actually given after a hinge response or at Review. |
| **WS** | Work completed with support in We-do or Independent; note the prompt level. |
| **I** | The pupil’s own independent content decision in Independent. |
| **NS+** | One specific next step given at Review or Exit, linked to the work. |
| **E** | E: evidence captured on {EVIDENCE_APP} — at Independent or Exit, only for an observed action. |
| **R** | At the next Arrival, the pupil responds to NS+ and the adult engages with it; then close the loop. |
| **//** | The point where the pupil actually self-edits after feedback at Review. |
| **?** | The Exit “Read it back” cue; receive the pupil’s response by their agreed mode. |

**Close the loop:** NS+ → pupil responds at a later opportunity (usually next Arrival) → adult engages with that response → R. `//` needs an actual self-edit. `?` needs a read-back response. E records actual evidence in the existing system.

## Four pupil-voice questions

1. What am I learning?
2. What feedback did I get?
3. What do I need to improve?
4. How do I know I've got it?

These are **illustrations from Job 9 tasks**, not assumed pupil statements or feedback. Replace them with the actual goal, actual feedback and the pupil’s own response. Pathways pupils may use BUILD with an adult and point, sign or use a symbol/AAC.

### Pathways

1. “I’m finding the school here” (points to the displayed goal or symbol with an adult).
2. “You said check the picture key” (shows or selects the actual cue).
3. “Next, this one” (points to the next single action).
4. “The L matches the key” (indicates the checked example).

### BUILD

1. “I’m learning the parts of this plant” (points to the diagram).
2. “You said I labelled the roots correctly.”
3. “Next I need to check the stem label.”
4. “The label points to the right part.”

### GROW

1. “I’m finding a grid square using eastings then northings.”
2. “You said I swapped the two pairs.”
3. “Next I’ll read eastings first.”
4. “The square matches both numbers on the grid.”

### LAUNCH

1. “I’m evaluating two climate responses.”
2. “You said my benefit needs a source.”
3. “Next I’ll add evidence and a limitation.”
4. “I used the same criterion for both choices.”

## Exit handoff

The TA tells the teacher **the deepest layer used**, **what the pupil did independently after it**, the response mode/access aid, and **one remaining barrier** linked to the task. The teacher selects one actual next step (NS+); at the next opportunity the pupil responds and the adult engages before R is used. Do not infer an EHCP outcome or invent a unit code.
