W1 GROW_SU1_W01

  1. Q1. Which map shows a school entrance best: world or site plan? ✓ Site plan ↳ World map
  2. Q2. Which map shows the UK among continents? ✓ World map ↳ Classroom plan
  3. Q3. What is a map scale choice based on? ✓ Detail the question needs ↳ Brightest colours
  4. Q4. A map has a symbol you cannot read. What do you check? ✓ Key ↳ Compass only
  5. Q5. Why use two maps for one place? ✓ They show different scales/details ↳ They must agree on every symbol
  6. Q6. Is a point on a world map enough to locate a school gate? ✓ No ↳ Yes

W2 GROW_SU1_W02

  1. Q1. In a four-figure reference, which numbers come first? ✓ Eastings ↳ Northings
  2. Q2. What does a four-figure reference identify? ✓ A grid square ↳ An exact point
  3. Q3. What should you do with an unfamiliar map symbol? ✓ Check the key ↳ Guess from colour
  4. Q4. How can you check a partner's grid reference? ✓ Find the square independently ↳ Repeat their answer
  5. Q5. What should match between atlas and digital map? ✓ Location and named feature ↳ Screen zoom
  6. Q6. If a reference is reversed, what likely changes? ✓ The selected square ↳ Nothing

W3 GROW_SU1_W03

  1. Q1. What makes a fieldwork count comparable? ✓ Same rule and named location ↳ Different features each time
  2. Q2. Where does a tally's total come from? ✓ Recorded marks ↳ Memory afterwards
  3. Q3. What must a claim about a pattern include? ✓ Count and location ↳ Only an adjective
  4. Q4. Can a classroom example count as real fieldwork evidence? ✓ No ↳ Yes
  5. Q5. What if the plotted value differs from the tally? ✓ Check both against record ↳ Keep the graph
  6. Q6. How can an accessible observation point still count? ✓ Use the agreed equivalent view and same rule ↳ Invent the count

W4 GROW_SU1_W04

  1. Q1. A river is usually which type of feature? ✓ Physical ↳ Human
  2. Q2. A bridge is usually which type? ✓ Human ↳ Physical
  3. Q3. What rule helps with a landscaped park? ✓ Name the specific feature and origin ↳ Call all parks physical
  4. Q4. Which explanation is stronger? ✓ The road is built, so human ↳ The road looks grey
  5. Q5. What if a photo does not show the feature clearly? ✓ Mark uncertain/check source ↳ Guess confidently
  6. Q6. How should a different classification be discussed? ✓ Use evidence and the agreed rule ↳ Vote by preference

W5 GROW_SU1_W05

  1. Q1. What makes two places comparable? ✓ Use the same criterion ↳ Use different criteria
  2. Q2. What must support a claim about each place? ✓ One source detail each ↳ A stereotype
  3. Q3. Is 'better' a clear comparison criterion? ✓ No; name a measurable feature ↳ Yes, on its own
  4. Q4. If source dates differ, what should you mention? ✓ The date limit ↳ Nothing
  5. Q5. What does 'both have a river' describe? ✓ Similarity ↳ Difference
  6. Q6. Can one selected image represent every part of a place? ✓ No ↳ Yes

W6 GROW_SU1_W06

  1. Q1. Which fieldwork value must match the graph? ✓ The recorded tally total ↳ A tidy round number
  2. Q2. What makes a conclusion supported? ✓ A recorded count and location ↳ An unsupported opinion
  3. Q3. What should a missing study section trigger? ✓ Check the evidence list and complete it ↳ Claim it is done
  4. Q4. What does UAS evidence need to show? ✓ Own completed work against the task ↳ A partner's work
  5. Q5. Should practice figures be labelled as fieldwork? ✓ No ↳ Yes
  6. Q6. What is a valid way to present a conclusion? ✓ Speech, AAC, typed or written with evidence ↳ Only handwriting
