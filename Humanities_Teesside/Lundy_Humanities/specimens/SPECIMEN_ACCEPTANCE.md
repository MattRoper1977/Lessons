# Humanities specimen acceptance

A specimen is accepted only if all are true:

- [ ] The lesson source file was not modified.
- [ ] The open decision was genuine and bounded.
- [ ] Historical validity was not settled by vote.
- [ ] Audience involved active restatement/listening.
- [ ] Influence received visible report-back.
- [ ] Staff interpreted evidence and changed teaching.
- [ ] One next step only.
- [ ] No branch code/score/tally was recorded.
- [ ] No second closure copy or receipt mark appeared.
- [ ] GROW/LAUNCH pupil-written close remained untouched.
- [ ] No catch-up debt or tutor queue was created.
- [ ] Source provenance and constructed status were clear.
- [ ] Access changed route, not the historical judgement.
- [ ] Authorship remained the pupil's.
- [ ] Personal/family disclosure was optional.
- [ ] No UAS/GCSE grade overclaim occurred.
- [ ] No safeguarding detail entered the evidence process.
- [ ] Pupil-facing candidate wording received Matt's explicit read before use.

Failure is information about the design. Remove or shrink the mechanism before scaling.
