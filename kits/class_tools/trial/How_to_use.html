Teacher tools trial: how to use it

Made by Matt. A free trial for class teachers. Open My tools to see every tool, or go straight to the Class record.

Three rules
  1. Pupils are numbers only. Never type a pupil's name into the Class record.
  2. Everything is saved on the device you are using, in that browser. These pages send nothing themselves and there is no login.
  3. Use the same device and browser each time, or your rows will not be there. Save a backup each week (Class record, Set up tab).

1. First time (one minute)

  1. Open the set up link your admin sent you, on the device you will use in class, and say yes. Your name, timetable, classes and skills list are filled in for you.
  2. Open Set up, then My weekly timetable, and correct any box that is wrong or empty. It saves as you type.

No link? Open Class record, choose Set up, and fill it in yourself.

2. After a lesson (under a minute)

  1. Class record, tab 1. Tap the lesson on today's strip. The class, subject and the right pupils appear.
  2. Type the lesson objective and tap a skill button. Same as last lesson fills both in for you. For English, Maths and Science, pick a skill with a code, such as R5 or M4. Those are the school tracker's skills, so the lesson feeds the tracker.
  3. Press All secure, then tap only the pupils who differ. Each tap moves on: Developing, Emerging, Absent. (These used to be called Got it, Partly and Not yet.)
  4. Press Save lesson to my sheet. The strip shows a tick for lessons you have logged.

Absent, Emerging and Developing pupils are marked as needing catch-up, with the skill they missed filled in.

3. My sheet

  • One row per pupil per lesson, like a spreadsheet. Click any cell to change it.
  • Use the note column for adaptive teaching you want to share, for example "works best with a worked example first".
  • Filter by pupil, subject or result, or show only pupils who need catch-up.
  • Change Catch-up to Done when the pupil has caught up.

4. Catch-up slips and sheets

  • Print catch-up slips gives one small slip per pupil listing what they still need to catch up.
  • Make catch-up sheets makes a one-page sheet for a missed lesson: what to know, quick tasks and a Show me box. Fill the boxes once, or leave them empty for a simple version, and it prints one sheet for each pupil who needs it.
  • If you keep your own sheets in a drive, paste the link for that lesson and open it from the same place.
  • This tool does not sign in to any drive. To keep files in your own drive, save them from here and put them in your drive folder yourself.

5. Sending your rows (two taps, any time)

  1. A bar at the top tells you how many rows you have not sent. Press Send to admin.
  2. Press Copy my rows and open the shared sheet. The school's shared sheet opens.
  3. On the Rows tab, click the first empty box in column A and paste. Your rows drop into place.
  4. Come back and press Done, I have sent it.

Backup route. If the shared sheet will not open, press Share the link or Copy the link and send it to your admin by school email or chat, or show your admin the QR code on your screen. The rows travel inside the link or code and hold pupil numbers only. You can still save a share file from My sheet if you prefer.

The school tracker

The shared sheet feeds the school's own tracker. It does not replace it. Each lesson tagged with a tracker skill code fills the Skills tabs in the shared sheet with that pupil's latest rating for that skill. A teacher then copies the new ratings across into the tracker. The tracker stays the master copy. Exam readiness is never filled in by these tools: it stays the teacher's own call in the tracker.

6. Other tools

My tools also has Quick capture, the Catch-up tracker, Lesson extras, Prompt studio, the Retrieval builder, the Practical log and more. They all work on this device only. Prompt studio builds prompts you can paste into an assistant your school allows; it sends nothing itself.

7. Optional extras (off until you switch them on)

  • Shared folder button. In Set up, paste your school's shared folder address. An Open shared folder button appears on My sheet.
  • Assistant buttons. In Set up, paste the address of an assistant your school allows. My sheet then offers Show the prompt, Copy prompt and Open assistant. The prompt holds pupil numbers and lesson details only. Read it before you copy it.

8. For the admin

  1. Open Class record, Admin on your own device.
  2. If you were given an admin file, press Load an admin file first. It fills in the timetables and classes.
  3. For each teacher: type their name and check their timetable boxes.
  4. Under For every teacher, set the classes with their pupil numbers, the skills list, and a message if you want one. Press Save admin settings.
  5. Press Show set up QR code and let the teacher point their camera at it, or press Copy set up link for each teacher and send it to that teacher only, by a private route such as school email. The link holds their name and timetable, and no pupil information. Opening it sends nothing anywhere. Send a new link whenever you change something.
  6. Put the shared spreadsheet file in your school's own shared place, shared only with the staff in the trial. Copy its sharing link into Shared sheet address for everyone, press Save admin settings, and send each teacher a new set up link or QR code. Their Send to admin button then opens the sheet for them.
  7. Fill in the Pupil key tab in the shared sheet once: for each teacher, which tracker Student goes with each pupil number. Then paste the Student list from the tracker into the Students tab. The Skills, Half-term review, Parents' evening and Leaders tabs fill themselves.
  8. The shared sheet counts results by pupil, by teacher and by skill on its own tabs. To see the same rows inside Class record, select the rows in the sheet, copy them, and paste them into tab 3, Central sheet, under Bring in rows from the shared sheet.
  9. Backup route: when a teacher sends you a link, open it on your admin device. When they show you a QR code, point your camera at it. Their rows land in tab 3, Central sheet. Use View to see every row, each pupil, each skill (who is not secure yet) or each teacher (what has been logged). Save any view as a spreadsheet file.

Names you type in Admin stay on your device and in the links and files you send. They are never part of the website.

9. Keeping it safe

  • If a note looks like it holds a pupil name or initials saved in Class names on that device, it is refused. You can add more blocked words in Set up.
  • The record still describes real pupils, so treat the files like any other school record. Ask your school's data lead before you start.
  • On a shared computer, use Clear my Class record on this device (Set up tab) when the trial ends.
  • This is a trial. Tell your admin what works and what gets in the way.
