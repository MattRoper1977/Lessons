Teacher tools trial: how to use it

Made by Matt. A free trial for class teachers. Open My tools to start, or go straight to the Class record.

Three rules
  1. Pupils are numbers only. Never type a name into the Class record.
  2. Everything is saved on the device you are using, in that browser. Nothing is sent anywhere and there is no login.
  3. Use the same device and browser each time, or your rows will not be there. Save a backup each week (Class record, Set up tab).

1. First time (about five minutes)

  1. Agree one number for each pupil with your colleagues, so Pupil 7 is the same child for everyone. Keep that list private, on paper or in Class names on your own device.
  2. Open Class record and choose the Set up tab. Pick who you are (Teacher 1, Teacher 2 and so on), the class size and your class code, then press Save set up.
  3. Optional: open My tools, then School Setup, to put in your own period times and subjects.

2. After a lesson (about one minute)

  1. Class record, tab 1, Add a lesson. Type the subject, the lesson objective and the skill or content taught.
  2. Press All got it, then change only the pupils who differ: Partly, Not yet or Absent.
  3. Press Save lesson to my sheet. Absent and Not yet pupils are marked as needing catch-up, with the skill they missed filled in for you.

If you already tallied the lesson in Quick capture, press Pull in Quick capture results instead, then add the objective and skill in My sheet.

3. My sheet

  • One row per pupil per lesson, laid out like a spreadsheet. Click any cell to change it.
  • Use the note column for adaptive teaching you want to share, for example "works best with a worked example first".
  • Filter by pupil, subject or result, or show only the pupils who need catch-up.
  • Change Catch-up to Done when the pupil has caught up.

4. The central sheet (once a week)

  1. Each teacher opens My sheet and presses Share: save my share file. The file holds numbers only.
  2. Put the share files in one place your school already uses, such as a staff shared folder, or hand them to one person.
  3. That person opens tab 3, Central sheet, and chooses all the share files together. They join into one sheet, sorted by class and pupil.
  4. Press Save central sheet as spreadsheet. The file opens in any spreadsheet program. Keep it on the school's own shared drive.

5. Optional extras (off until you switch them on)

  • Shared folder button. In Set up, paste your school's shared folder address. An Open shared folder button appears on My sheet.
  • Assistant buttons. In Set up, paste the address of an assistant your school allows. My sheet then offers Show the prompt, Copy prompt and Open assistant. The prompt holds pupil numbers and lesson details only. Read it before you copy it.

Leave either box blank to keep it switched off.

6. Keeping it safe

  • If a note looks like it holds a name or initials saved in Class names on that device, it is refused. You can add more blocked words in Set up.
  • The record still describes real pupils, so treat the files like any other school record. Ask your school's data lead before you start.
  • On a shared computer, use Clear my Class record on this device (Set up tab) when the trial ends.
