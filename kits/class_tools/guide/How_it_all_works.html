How it all works

My page

I want to find my way back
  1. Start on My page.
  2. Choose Lessons to see the lesson list.
I want to find the class tools
  1. Start on My page.
  2. Choose Tools to see your class tools.
  3. Open My tools to see your day.

Apps

I want to open an activity
  1. Choose Apps from the site menu.
  2. Press Browse the suite.
  3. Choose an activity from the list.
I want to return to my lessons
  1. Return to My page.
  2. Choose Lessons to return to the lesson list.

Lessons

I want to find this week’s lesson
  1. Open Lessons.
  2. Type the topic or week in Search.
  3. Select the lesson title you want.
I want to print one pupil’s adapted pack
  1. Open My pupils in the lesson.
  2. Find the pupil and press Print adapted pack.

Tools

I want to open today’s lesson in one press
  1. Open My tools.
  2. Press Start my day.
  3. Use Quick capture on the period card to record a result.
I want to move my pupils to another device
  1. Open Class names on your own device.
  2. Press Save private copy and move the copy privately.
  3. On your other device, press Load private copy.
  4. Check the pupil numbers and press Save on this device.
I want to save a private copy
  1. Open Class names.
  2. Press Save private copy.
  3. Keep the file in your private folder.
