Missed last week

The lessons that did not run while you were off, each with its ready-made catch-up sheet (print and go, answers on page 2) and the best slot to use it this week. Ticks and private pupil help stay on this device. Printed lists use Pupil N.

How to use a sheet

  1. Print it (or open it on the board). Page 1 is for pupils, page 2 is your answers.
  2. Run it as the first 15 to 20 minutes of the slot shown, or in any spare lesson time.
  3. Tick it off here. If only some pupils still need it, add them in the catch-up tracker instead.
