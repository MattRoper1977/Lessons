Class names (private)

Nothing you type here is sent anywhere. This page has no server and saves nothing online. The names only leave this page when you press Save names file.

One name per line. First name and surname is best.

Then

  1. Press Save names file. It saves names.txt to your downloads.
  2. Put that file in Google Drive, in MBM private tracker (do not share) › Names inbox.
    On a phone: open Downloads, tap the file, Share, Drive, then pick that folder.
    On a computer: open that Drive folder in the browser and drag the file in.
  3. Within 15 minutes the home laptop takes the newest file as your names list. Its status note in Drive says when.

To change the list later: open the last names file you saved (Open a names file), change it, and save again.
