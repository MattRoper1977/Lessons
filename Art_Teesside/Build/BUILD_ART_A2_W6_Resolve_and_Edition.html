What is registration?

Lining the stencil up the same way each time.

What makes five prints a SET rather than five separate things?

They share the image, the colours and the placement — consistency is what makes it an edition.

1. Last lesson (Recall)

Why can adding paint never rescue mud?

It adds another colour to the mix; only removal restores separation.

What is a wash for?

Tinting without covering.

Carried in different places at once, and replaceable when damaged.

Defensible either way — hand-pulled editions vary; the argument is what matters.

Starter

Starter: Knowing When to Stop

Key question: Two finished pieces. One stopped at the right moment. One kept going for ten more minutes and lost.
Finishing is a decision, not running out of time. The question is not “is there anything else I could add?” — there always is. It is “would adding it make this say more?”
I Do

I Do: Stopping, Then Repeating

Key idea: I call mine finished and say the one thing I chose NOT to add. Then I pull it again — same stencil, same dabs, taped to the paper — and we compare the two.
🔍 Spot it, then fix it
❌ Drifting — the stencil moved, so none of them line up
❌ Soft — sponge overloaded, edges gone furry
✅ Right — five that clearly read as a SET
Tape the stencil to the PAPER, not the desk. Reload the sponge the same number of dabs every single time. Consistency is the whole skill here.

We Do — the surfaces / cards

Tape to the paper NOT THE DESK. If the stencil is fixed to the desk and the paper moves, every print drifts.

Count your dabs SAME EVERY TIME. Three dabs means three, on print one and print five. This is what makes a set.

Same order REPEAT THE SEQUENCE. If rubbing came first once, it comes first every time.

The stop line NAME WHAT YOU DID NOT ADD. That sentence is the evidence you stopped on purpose.

Where each one goes KEEP ONE, PLACE FOUR. Corridor, reception, a named adult, a peer. Write down where each went.

Three is still an edition THE SHRINK LINE. If five is not happening, three is a set. A smaller edition is a finished edition.
