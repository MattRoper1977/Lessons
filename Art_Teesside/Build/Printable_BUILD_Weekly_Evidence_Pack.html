How to use: pick a week, print the sheet, and it matches that lesson on screen — same stamped ticket, same Teesside-tinted Lundy zones, same BUILD→GROW ladder. One sheet per pupil per week. Capture independence, not volume. No pupil names are stored in any file.
Portfolio of record: this weekly sheet is the portfolio of record. The print-sections inside each lesson file are working documents — they support the task, they are not the evidence the adviser audits. If a piece of working paper matters, mount or photograph it onto the week sheet and give it a reference.
