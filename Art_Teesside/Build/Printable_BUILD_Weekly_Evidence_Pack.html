BUILD Explore Art · Printable Weekly Evidence Pack

Made by Matt · madebymatt.uk · Trinity Arts Award Explore (supported) · Autumn 1 · 2026–27

How to use: one week, one A4 page. Print the week you are on. This sheet is the portfolio of record — the print-sections inside each lesson file are working documents. Mount or photograph anything that matters onto the week sheet and give it a sheet reference. No pupil names are stored in any file; a code works everywhere a name would.

Large print scales the type and spacing of this pack. Nothing is removed — the sheets simply run onto more pages, which is the honest trade for legibility. PRINT-UNVERIFIED: print one week both ways on paper before issuing.
