Teaching script 1

Arrival · 4 min

Invite a private regulation check. Green · Ready, Amber · Help, Red · Pause. Offer a quiet start, usual aid or pass. Use the cue and accept the pupil’s usual communication mode.

Starter · 2 min

Starter question 1 revisits last week. Take one minute for recall and reveal. What did a fair test help you find last week? Cue: Test · result. Expected: It showed how the model worked under agreed conditions. Keep the actual result. Then ask: Does a build photo prove how much a model can hold? Expected: No. A build photo shows shape. Use the actual test record for the result. Use the made-up task. Begin in your book.

Teaching script 2

I do · 5 min

Watch, choose and check. Order plan, build and test records. Caption what each record shows. Link a result to a possible change. Adult example: the test note says the centre bent. A folded edge might help. Retest with the same gap and agreed load steps. Keep the first try. Ask if a step is unclear. Use your usual aid.

We do · 5 min

An earlier fold has no photo. Which record is honest? Ask for a choice and a reason before revealing. B. Keep the gap clear. Use an actual note or labelled later drawing. Use a separate example: the join slipped in the test. Explain why a closer join may help. Keep this as a proposal.

You do · 17 min

Keep first work and any change separate. Read or scribe exact pupil words as needed. Open your book. Add Plan, Build and Test headings. Match your actual records to those stages. Teaching script 1

Arrival · 4 min

Invite a private regulation check. Green · Ready, Amber · Help, Red · Pause. Offer a quiet start, usual aid or pass. Use the cue and accept the pupil’s usual communication mode.

Starter · 2 min

Starter question 1 revisits last week. Take one minute for recall and reveal. What did a fair test help you find last week? Cue: Test · result. Expected: It showed how the model worked under agreed conditions. Keep the actual result. Then ask: Does a build photo prove how much a model can hold? Expected: No. A build photo shows shape. Use the actual test record for the result. Use the made-up task. Begin in your book.

Teaching script 2

I do · 5 min

Watch, choose and check. Order plan, build and test records. Caption what each record shows. Link a result to a possible change. Adult example: the test note says the centre bent. A folded edge might help. Retest with the same gap and agreed load steps. Keep the first try. Ask if a step is unclear. Use your usual aid.

We do · 5 min

An earlier fold has no photo. Which record is honest? Ask for a choice and a reason before revealing. B. Keep the gap clear. Use an actual note or labelled later drawing. Use a separate example: the join slipped in the test. Explain why a closer join may help. Keep this as a proposal.
