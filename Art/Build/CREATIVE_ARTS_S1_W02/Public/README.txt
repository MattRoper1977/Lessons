CREATIVE ARTS SPRING 1 WEEK 2
Theme: Resilience & Change. Year A. Both pathways: Explore.

This folder is a complete portable edition. Keep assets beside the lesson pages. Both editions have the same generic classroom content.

START HERE
Read Sequence_and_Evidence_Guide.pdf and the dated Teacher_and_Cover_Plan.pdf. Use the interactive HTML or editable slides. Pupil_Resources.pdf is the checked print pack; Editable_Pack.docx supplies editable pupil pages. Separate knowledge organisers, word pages, route packs, activity cards, model/test comparisons, evidence slips, staff answers and TA briefs are supplied.

TIMING
Each lesson is 40 minutes. Arrival 3; Starter 3; I do 6; We do 6; Create 14; Review 5; Exit 3. Tidy in the last two Review minutes. Model, route and optional stretch slides use time within these stages.

BUILD PROGRESSION
Choose an emotion for an invented piece. Make two small tests, a tiny ordered trial and a start/end plan in the first lesson. Use the real plan to create and review the piece in the second. If a plan is absent, make an honest short restart and keep the actual date. Do not require personal disclosure.

GROW BEFORE AND AFTER
Each pupil chooses one technique and keeps it across both periods. Retain the first test before modelling, a small target and practice notes. In the second period repeat the same four-part test with the same form and size or pace guide. Keep the actual after result and a specific comparison, even if the skill is unchanged or less secure. Record help used. If access requires a form change, retain the old record and start a new before test for the new form. Never invent a missing baseline.

ACCESS AND GUIDANCE
Every lesson stage has what to say, what good looks like and a materials-free fallback. Pupils can work silently, direct an adult and share privately. Books and existing arts logs come first. Typing is optional and closed under Type instead. Save my responses creates a local text file; it does not submit work. No pupil login, instrument or recording device is required. Sound stays below talking volume and stops on a raised hand.

EXPLORE AND STRETCH
One clearly labelled optional next level stretch is included per GROW lesson. Explore learning stands complete without it. Keep any extra pupil-owned goal, practice, comparison and reasoned view separately labelled. The week contributes to the ongoing arts log and does not by itself complete an award.

VISUALS AND LOGS
The original teacher-model sheet is a general example, never a pupil baseline or after test. No copied artwork, lyrics or quotations are supplied. The approved mark is unchanged. Continue dated log entries in the existing five-file pattern if used. The blank templates are optional. A classroom discussion does not prove a visit or live encounter.

CHECKS AND LIMITS
CHECKS.json and CHECKS.txt record checks. Print PDFs, document pages and editable slides were rendered and visually reviewed. Interactive code and simulated interactions were checked. Full browser rendering and HTML print pagination were not executed; use supplied PDFs for checked print geometry. READING_FIGURES.json retains exact measured pupil corpora and estimates, not learner assessments. No standalone scripts are included. All resource links are relative.
