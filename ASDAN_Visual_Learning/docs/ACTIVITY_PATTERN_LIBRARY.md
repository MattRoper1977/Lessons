# ASDAN activity pattern library

These patterns are designed for teacher-led rehearsal followed by an authentic ASDAN task. None awards a grade, evidence state, criterion, certificate or portfolio decision.

## 1. Click-to-place classification

**Use for:** strengths, needs and wants, food groups, roles, hazards, tools, evidence forms.

**Interaction:** choose a card, then a destination. Dragging may be offered as an optional pointer shortcut, but click-to-place is always complete.

**Teaching move:** ask for the deciding feature before placement.

**Independent transfer:** classify a new real or fictional example and state the observable reason.

## 2. Safe sequence builder

**Use for:** routines, applications, hygiene, tool processes, project planning, contact and handover.

**Interaction:** move rows with native up/down buttons; check the whole chain.

**Teaching move:** ask “what must already be true before this step?”

**Independent transfer:** create or follow the real sequence without copying the finished model.

## 3. Evidence or distractor audit

**Use for:** employability evidence, project need, communication evidence, portfolio quality, source quality and evaluation.

**Interaction:** select the complete valid set; reject labels, praise, guesses, invented records and unsafe shortcuts.

**Teaching move:** distinguish “sounds positive” from “shows an observable action or result”.

**Independent transfer:** locate one authentic example in the real task.

## 4. Hotspot investigation

**Use for:** community maps, rooms, workplaces, labels, project boards, hazard scenes and stakeholder systems.

**Interaction:** numbered keyboard-operable hotspots open one relationship at a time. Opened notes remain visible.

**Teaching move:** compare the whole system after all points are open.

**Independent transfer:** annotate the real place, object, task or plan.

## 5. One-variable model

**Use for:** budgets, prices, break-even, routine reliability, hygiene controls, project readiness, message quality and task quality.

**Interaction:** choose values, predict, run, freeze and retain the result. GROW/LAUNCH require a second run with exactly one change.

**Teaching move:** name the fixed conditions and the changed variable.

**Independent transfer:** make a justified change in the real task.

## 6. Before / controlled change / after

**Use for:** profile writing, cleaning, practical quality, communication, design, feedback and review.

**Interaction:** preserve the baseline, reveal one controlled change and compare the result.

**Teaching move:** prevent the improved version from erasing the evidence of development.

**Independent transfer:** retain or describe both versions in the authorised lesson process.

## 7. Claim → action → result chain

**Use for:** strengths, employability, PEQ skills and reflection.

**Interaction:** connect a broad claim to an observable action and a consequence or recipient.

**Teaching move:** remove unsupported adjectives.

**Independent transfer:** complete “I did… / This shows… / It helped or changed…”

## 8. Need → evidence → aim filter

**Use for:** community projects and enterprise.

**Interaction:** separate a real evidenced need from an adult preference, broad complaint or invented partner request.

**Teaching move:** ask whose need is being described and what evidence exists.

**Independent transfer:** write a bounded aim that can be checked.

## 9. User → problem → response map

**Use for:** enterprise, service design, careers and community action.

**Interaction:** align one user, one problem and one feasible response.

**Teaching move:** reject an attractive product that does not answer the need.

**Independent transfer:** create a user sentence and one testable response.

## 10. Hazard → control → check

**Use for:** home, kitchen, gardening, hospitality, workshop and off-site tasks.

**Interaction:** match the hazard to the control and the adult or pre-use check.

**Teaching move:** a control is not permission; current local procedures govern.

**Independent transfer:** follow the school’s real risk assessment and adult instruction.

## 11. Cost → price → result model

**Use for:** budgets and enterprise.

**Interaction:** alter one figure, freeze the balance or break-even effect and compare.

**Teaching move:** use fictional figures only; never enter a pupil’s real financial data.

**Independent transfer:** calculate the authorised classroom scenario.

## 12. Structured evidence locator

**Use for:** LAUNCH after the investigation.

**Interaction:** choose one option in each group: what exists, where it is, and the authorised next route.

**Teaching move:** “not yet available” and “not yet located” are honest outcomes. The locator does not judge achievement.

**Independent transfer:** use the real teacher/assessor workflow outside the panel.

## 13. Role and dependency board

**Use for:** teamwork, project roles, vocational roles and events.

**Interaction:** show what each role produces, receives and hands on.

**Teaching move:** distinguish a title from a responsibility.

**Independent transfer:** complete the assigned role and record support honestly.

## 14. Message / audience / action check

**Use for:** applications, partner contact, promotion, pitches and presentations.

**Interaction:** change audience, purpose, evidence and next action; freeze the effect.

**Teaching move:** a polished message is not effective unless the intended recipient can act on it.

**Independent transfer:** create the real message through the authorised communication route.

## 15. Plan → action → evidence → review rail

**Use for:** PEQ, projects, challenges and portfolio completion.

**Interaction:** trace the relationship while keeping each stage distinct.

**Teaching move:** the screen rehearses the structure but does not manufacture evidence.

**Independent transfer:** identify the real item, action and authorised review route.

## Common accessibility rules

- Native controls first.
- Touch target at least 44 CSS pixels.
- Enter and Space work without custom key combinations.
- Symbol, border and text repeat every colour state.
- No time-limited response.
- No drag-only completion.
- Wrong answers explain the relationship and permit another attempt.
- Reduced motion resolves instantly with no hidden content.
- Print suppresses transient controls.
- Reset removes all temporary state.
