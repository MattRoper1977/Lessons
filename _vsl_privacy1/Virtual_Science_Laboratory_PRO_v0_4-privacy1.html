Using the Virtual Science Laboratory

Introduce · 0–10 min

Make a prediction, identify variables or technique decisions, and inspect the apparatus before collecting evidence.

Explore · 10–25 min

Change one factor, run repeats, use authentic-noise mode if appropriate, and record observations/data.

Do · 25–40 min

Calculate, interpret graphs, identify concordance/anomalies, and write a scientific explanation or exam-style response.

Calm Mode

Removes rapid visual movement and uses a light, lower-stimulation interface. Core results stay the same.

Share

Encodes the current bench, settings and logged evidence into the URL fragment. No account or server is required.

Evidence

Print a practical record, copy data as TSV, generate an exam schematic or export local JSON. Nothing is uploaded automatically.

Spatial Sandbox

Drag, snap, rotate, pour, heat, connect flexible tubing and allow mistakes to produce diagnostic virtual consequences.

Microscale Analysis

Use separate wells and correct acidification sequences to avoid false positives in qualitative ion tests.

Teacher note: this prototype intentionally avoids instructions for unsupervised home chemistry. Apparatus behaviour and observations are simulated, not an invitation to recreate procedures outside a suitably managed laboratory.
