We Do · think together

Choose the right explanation

Match each observation with the relevant idea, then improve one sentence.

A model helps explain an idea. It does not measure real planetary motion or prove an observation. Label any given numbers as reference values.

  1. A: A crescent becomes a half-Moon view.
  2. B: Earth’s shadow crosses the Moon in a lunar eclipse.
  3. C: The Moon keeps nearly the same face towards Earth.

Discuss, point, draw, write or dictate a first explanation. Choose one example first; extend only if there is time.

Reveal a worked explanation after an attempt

A: changing view of the sunlit half during the orbit. B: Earth blocks sunlight in the eclipse alignment. C: the Moon rotates once for each orbit. Ordinary phases are not the Earth’s shadow.

Give a smaller support cue

Say what you first thought, point to the model evidence, then change one part of the same explanation.

Apply it

Use the current workshop

Check three model views, record one correction and explain a limitation. Use the two period values to distinguish an orbit from a phase cycle if ready.

Teacher model · compare with the pupil’s evidence

Model answer: I corrected the half-Moon drawing so the circle stayed round and only half the visible face was lit. The torch-and-ball model helps show the changing view, but its distances and sizes are not to scale. About 27.3 days describes an orbit; about 29.5 days describes the repeating phase cycle.

I Do · explain and model

Look, explain, check

Keep the light direction fixed and choose one observer position.

Check the new, side and full views with a ball or still diagram.

Keep the Moon round in every drawing. Change the portion shown lit.

Connect the ideas

One orbit relative to the stars takes about 27.3 days.

A new-Moon-to-new-Moon phase cycle takes about 29.5 days.

Both are roughly a month, but they describe different repeating relationships.

Quick check

A torch-and-ball model puts the ball in your head’s shadow. Does that show an ordinary Moon phase?

Check the explanation

No. That blocks the light and models an eclipse-like shadow. Keep the ball slightly above the head’s shadow when modelling ordinary phases.

It turns once for each orbit. Use the still model to track a marked Moon face. This animation explains a relationship; its scale is simplified.

For the adult

Preparation and a likely misconception

Keep Monday’s cards. Offer three-view drawing or directing an adult’s model. Restore room conditions promptly. The NASA video is optional; the same question can be answered using the still model.

Watch for: A model observation is not a measurement of the Moon’s real orbital period.
