We Do · think together

Repair the plan

Choose the first changes needed to make this method useful.

Use the model to explain or predict. Only record observations and practical steps that actually happened.

  1. “Use two different trolleys.”
  2. “Push until it feels fast.”
  3. “Measure from wherever the ruler starts.”
  4. “Keep only the longest result.”

Discuss, point, draw, write or dictate a first explanation. Choose one example first; extend only if there is time.

Reveal a worked explanation after an attempt

Use the same trolley and a fixed no-push release. Measure from a marked zero to the same trolley edge. Keep and compare repeated results, noting mistakes. Changing several things prevents a clear causal conclusion.

Give a smaller support cue

Use the three headings CHANGE / KEEP / MEASURE. Give one item under each before extending.

Writing stays in this open page only. It is not saved or sent. Copy any record you want to keep before leaving.

Apply it

Use the current workshop

Complete a plan with the question, CHANGE, MEASURE with unit, at least two controls and three repeats per surface. Sketch the starting mark and measuring zero.

Teacher model · compare with the pupil’s evidence

Question: does run-out surface affect stopping distance? CHANGE: surface. MEASURE: stopping distance/cm. KEEP: trolley, ramp height, release point, no push and the measuring method. Run three trials on each surface and keep every result.

I Do · explain and model

Look, explain, check

Question: does the run-out surface affect how far the same trolley rolls?

Change the surface. Measure stopping distance in centimetres.

Keep the trolley, ramp height, release point and no-push release the same.

Connect the ideas

Write the plan before using equipment. Label the ruler zero.

Repeat each surface using the same measuring point on the trolley.

A test can be controlled even when people take different roles. “Fair” here describes the comparison.

Quick check

Two trolley runs have different surfaces and different pushes. Which change caused the longer distance?

Check the explanation

The evidence cannot separate the causes. We need a controlled release and one planned variable change.

The same science without video

The wheel is turning and the brake pad presses against its rim. Predict what happens. Does that scenario supply any controlled stopping-distance measurements for our two-surface trolley test?

Teacher explanation for the video or still scenario

No. It shows a wheel slowing as the brake grips. It does not compare our two surfaces with controlled releases or provide our repeated measurements.

Use a short extract or the still scenario in place of part of the modelling time. A video or model is not evidence that pupils completed a practical.

For the adult

Preparation and a likely misconception

Prepare planning cards and a drawing of the secured setup. Demonstrate a no-push release if suitable. Tuesday uses the same plan; save each pupil’s first version and agreed correction.

Watch for: Repeats do not repair an unfair method. A clear question and controls come first.

Exit question and model answer

What is the difference between a control variable and a measured variable?

Reveal a worked explanation after an attempt

We deliberately keep a control the same; the measured variable is the result we record.
