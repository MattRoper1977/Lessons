# SCI_LAUNCH_SU1_W02 · TA deployment brief

**Objective:** Model blood-glucose control (interactive software).

## EEF five-layer scaffolding key

**Self-scaffold → prompt → clue → model → correct.** Move down only when the pupil can't go on; move back up as soon as they can. Start by waiting, checking the pupil’s own attempt and using the existing visual, communication or reading aid. An access aid is not a content answer.

1. **Self-scaffold — watch for:** Predicts the model’s response to the changed input. Let the pupil check the source, key, diagram or own work before speaking.
2. **Prompt — two open questions:** “Which hormone responds to rising glucose?” “Why must the chosen response move the level toward the range?” Pause after each; accept point, sign, AAC, speech or writing.
3. **Clue — two narrowed questions:** “Does the graph first rise or fall?” “Which hormone has the opposite effect to the one chosen?” Give one clue at a time and then step back.
4. **Model — one step only:** Show one first step: Start with the graph arrow and choose 'up' or 'down'. Then the pupil tries the next matching move with the source in view.
5. **Correct — one direct fact and when:** If the pupil still cannot continue after that model, give only “Insulin.” for “Blood glucose rises after a meal. Which hormone helps lower it?”. Then ask for a fresh application, record the level used and fade back toward self-scaffolding.
