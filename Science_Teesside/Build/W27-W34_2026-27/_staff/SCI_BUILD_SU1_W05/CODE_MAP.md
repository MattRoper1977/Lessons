# SCI_BUILD_SU1_W05 · code map

Objective: Set up and observe a plant-growth investigation over time (ICT to record).

- **VF** — After the I-do hinge or at Review, the adult gives verbal feedback about the actual response to “I can record a dated observation of the actual plant and compare the same measure over time”.
- **WS** — In We-do, record actual scaffolded work on the ladder and the prompt level; access aids alone are identified separately.
- **I** — At Independent application (scheme-level proposed stage; verify against a real lesson), mark only a pupil’s own independent content decision or explanation.
- **NS+** — At Review / Exit, name one specific next step from the hinge, work or exit evidence; leave blank if none given.
- **//** — At Review, mark the point where the pupil actually self-edits a response against feedback or the criterion.
- **?** — At Exit, press “Read it back (?)” and hear, see or receive the pupil’s read-back by their agreed mode.
- **R** — At the next lesson Arrival, receive the pupil’s response to the NS+ and engage with it; close the loop then, not when NS+ is first given.
- **E** — At Independent / Exit, capture only observed Job 2 evidence if it occurs: communication & interaction: Reports a dated change in the observed plant; cognition & learning: Records a comparable observation at the agreed interval; SEMH: Requests help or an agreed pause during the practical recording task; sensory & physical: Uses an adapted grip, scoop or watering aid to complete an agreed setup step. Use the existing evidence record.

Codes show possible walk-visible moments, not claims that they happened. Do not assign a code merely because its line appears here.
