Build a Rock Sorting Key

Learning objective

I can build and test a yes/no sorting key using visible rock evidence.

Success looks like

  • Ask an observable yes/no question.
  • Use the same question for every specimen.
  • Test the key with Mystery T and explain the route.

A mystery arrives. Will your sorting key work without changing its rules?

W9B · one 40-minute lesson

Seven stages, with one arrival and one exit. Use the route that helps you show your science today.

No earlier worksheet is needed. Fresh evidence is included.

Point, speak, sign, move cards, draw, write or direct an adult. Use one response mode; no separate participation form.

Learning objective

I can build and test a yes/no sorting key using visible rock evidence.

Key words

key — A sequence of questions used to sort or identify within a set.

criterion — The feature that decides a group.

consistent — Using the same meaning each time.

uncertain — Evidence is not clear enough to decide yet.

Remember

  • Ask about a feature that is visible on the supplied card.
  • YES and NO must refer to the same question.
  • A key may group specimens without uniquely naming them.
  • Keep an unclear view uncertain rather than guessing.

Success looks like

  • Ask an observable yes/no question.
  • Use the same question for every specimen.
  • Test the key with Mystery T and explain the route.

BUILD Science · Sugar Evidence: Read the Label · Supported

Your task

1. Use these fictional teaching cards. All give sugar in g per 100 g: A — 4 g; B — 9 g; C — 14 g; D — 23 g.

Help with this question

Use a paper strip to track one card at a time. Say or point to the letter, the sugar number and ‘g per 100 g’ together.

2. Put the four cards in order from LEAST sugar per 100 g to MOST. Point, move paper cards or direct an adult.

Help with this question

Compare two numbers first. Place the smaller one towards LEAST, then find where each remaining card belongs.

3. Complete: Label ___ has the least sugar per 100 g. Label ___ has the most.

Help with this question

Look at the two ends of your own order. Use those card letters to fill the gaps.

4. Choose the claim we can support: 'A has less sugar per 100 g than D' / 'A is the healthiest food for everyone'.

Help with this question

Ask: does this sentence describe the sugar evidence, or claim to know everything about the food?

5. Finish or point: These sugar numbers show ONE PART OF NUTRITION / THE WHOLE EATING PATTERN. Keep “g per 100 g” with each number.

Help with this question

Look at what was measured. Think about whether these cards show every nutrient and everything a person eats.

BUILD Science · Sugar Evidence: Read the Label · Standard

Your task

1. Read these fictional teaching labels. Each is PER 100 g. A: carbohydrate 22 g; of which sugars 4 g. B: carbohydrate 67 g; of which sugars 9 g. C: carbohydrate 58 g; of which sugars 14 g. D: carbohydrate 72 g; of which sugars 23 g.

Help with this question

Track the ‘of which sugars’ row. Keep the carbohydrate and sugar rows separate.

2. Make a results row for each label. Copy the SUGAR value with its unit and basis; do not copy total carbohydrate.

Help with this question

Use the headings Label | Sugar / g per 100 g. Check each copied value against its nutrient name.

3. Order A–D from least to most sugar per 100 g.

Help with this question

Check adjacent pairs: is each value no larger than the next? Recheck that all four use the same basis.

4. Write or say one comparison: 'Label ___ has ___ g sugar per 100 g. This is less/more than ___.'

Help with this question

Build the comparison from two complete readings. Include which label you are comparing it with.

5. Explain one thing these sugar numbers cannot tell us about the whole food or eating pattern.

Help with this question

Choose one missing piece of information. Explain why that missing information limits a wider judgement.

BUILD Science · Sugar Evidence: Read the Label · Stretch

Your task

1. Fictional labels, all PER 100 g: A — carbohydrate 22 g, sugars 4 g; B — carbohydrate 67 g, sugars 9 g; C — carbohydrate 58 g, sugars 14 g; D — carbohydrate 72 g, sugars 23 g.

Help with this question

Identify the nutrient and reference amount before selecting numerical evidence.

2. Extract the four sugar values and order them. Keep the unit and basis.

Help with this question

Audit the completed order against the source labels; a correct number copied from the wrong row is still the wrong evidence.

3. Extra label E says 'sugars 3 g per 25 g serving'. Someone puts E before A because 3 is less than 4. Audit this decision.

Help with this question

Compare the reference quantities before comparing the two bare numbers.

4. Put E on a per-100 g basis before comparing. How many 25 g servings make 100 g? Then place E among A–D.

Help with this question

Find the scale factor from 25 g of food to 100 g of food. Apply the same factor to the sugar amount.

5. Write one supported comparison from A–D and repair this claim: 'The lowest-sugar card proves the best food for everybody.'

Help with this question

Separate a justified numerical comparison from a wider judgement. State exactly what the evidence establishes and what it leaves unknown.
