## Faded example, tiered task and stretch

In We do, show “This sheet has a blank back. I can write there. I put it in ____.” The removed step is **The category Use less is missing; pupil completes the category and gives a reason.** In Independent, the pupil selects a clean object or card without a filled step. Next time, **Next lesson show the item only; pupil names an action, a category and a reason.**

We do **F support:** Point to the back. Say Use less. **M:** sort a card and say why. **H stretch:** Why use the back before the bin? Then Independent **F:** Pick one way to use less. **M:** Show one item you can use again. Say why. **H:** Which uses less new stuff: fill a clean tub again or take a new tub? Why? All pupils hear the core question. Speaking frames appear before writing frames; on-page tier stems: F “I use less when I ____.” / M “I can use ____ again because ____.” / H “I choose ____ because it needs less ____.”

**Go deeper:** Could one safe item be used again before it is sorted for a bin? Show how. **Named harder early-finisher stretch — Waste route judge:** Tub or sheet: pick a first step for each. Which avoids a new item? Why? This asks for a justified comparison, not extra cards.

## Hinge and teaching decision

**Question:** A clean cloth bag is ready for another trip. Which choice uses less new material?

| Option | Correct? | Diagnosis |
|---|---|---|
| Take a fresh new bag. | no | Takes a new item rather than reusing one. |
| Throw the cloth bag away. | no | Confuses disposal with using less. |
| Use the cloth bag again. | yes | Reuses the clean item before needing a new one. |
| Keep two new bags ready. | no | Adds new items without a need. |

**Rule:** About 3 in 4 or more right → move on; otherwise re-model with a clean refillable tub and ask the parallel hinge. Do not save or score. **Parallel hinge:** A clean bottle can be refilled for another drink. What uses less new material?

**Misconceptions:**

| Misconception | How to spot it | Correction |
|---|---|---|
| Reusing and recycling mean the same thing. | Pupil says the clean tub must be broken down before it can be filled again. | Show the same tub used again; recycling makes a new thing from old material. |
| Any old thing goes in any recycling bin. | Pupil puts all example objects in one real bin without checking. | Use labelled practice trays and check local bin instructions before a real bin is used. |

## Prepared model handling · practical safety

**Kit:** Clean adult-checked object or matching large card, tray

**Method:** Choose one checked item or matching card; sort it; record a reason.

**Pupil Risk:** An unknown reused item could have a dirty or sharp edge.

**Pupil Safe:** Use only clean adult-checked items or cards. Leave unknown waste alone; wash hands after shared objects.
