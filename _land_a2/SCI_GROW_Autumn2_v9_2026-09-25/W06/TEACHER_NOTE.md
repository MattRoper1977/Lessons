## Faded example, tiered task and stretch

I do full: “Change rough/smooth surface → keep toy, start and launch the same → measure distance → repeat.” We do part-done: “Change ____ → keep toy and ____ the same → measure distance.” **Removed step:** Name surface as the changed factor and a consistent launch as a control. Independent: no filled step. **Next fade:** Next time give only the question; ask pupils to select the changed factor and two controls without a filled plan.

We do F: Use a visual card for toy, start mark and launch; point to the missing control. M: Name two controls and record a result. H: Explain how a different launch could make a surface comparison misleading. Independent F: Point to the factor that changes. M: Name two controls and record a result. H: Explain why repeat runs help and identify a method limit. **Go deeper:** Two runs differ. Name a reason and fix a method step. **Named harder stretch — Fair test repair:** Two repeats differ. Name a safe conclusion, then improve the method for the next test.

The model, source or practical route is: small toy, two safe surfaces, ruler and start marker. Two on-screen interactions are card sort and What should you do if two repeat runs disagree?; native keyboard controls, live feedback, no storage. The diagram is original and simplified, not to scale. Its labels are checked in the facts ledger.

**Practical:** Predict first: Will the toy go farther on rough or smooth paper? Give a reason. Kit: Small toy, Low launch guide, Rough and smooth paper, Start-line tape, Ruler. Steps: Mark one start and use the same toy; Launch twice on rough paper in the same way; Measure and record each distance; Repeat on smooth paper; change only the surface; Compare runs and name a limit. Results table: Surface | run 1 (cm) | run 2 (cm), Rough | ___ | ___, Smooth | ___ | ___. Check against the school risk assessment and CLEAPSS guidance. Keep the track low and clear; avoid raised drops and mains equipment. Do not invent or change results.

## Hinge and decision

**Question:** A team compares carpet and vinyl using one trolley. Which plan lets them test the surface fairly?

| Option | Correct? | Diagnosis |
|---|---|---|
| Same push; change start and surface. | no | Changes the start as well as the surface, so the comparison is confounded. |
| Same start; change trolley and surface. | no | Changes the trolley as well as the surface, so the comparison is confounded. |
| Same surface; change trolley and push. | no | Keeps the surface and changes both the trolley and push; it cannot test surface effect. |
| Same start and push; change surface. | yes | Uses the new case accurately. |

**Rule:** About 3 in 4 or more right → move on. Otherwise re-model with the named I-do example, then ask the parallel hinge. **Parallel:** A new team compares felt and foil with a sliding block. What stays the same: block and push, or surface? Answer: block and push; surface changes.

**Misconceptions:**

| Misconception | Spot | Correct |
|---|---|---|
| A fair test may change the trolley and surface together. | Pupil chooses B, changing trolley and surface together. | Change only the surface; keep the trolley, start and push alike. |
| Holding the surface fixed while changing trolley and push tests the surface. | Pupil chooses C, changing trolley and push but not the surface. | The changed surface must be the variable under test. |

## Adults, regulation and prompt ladder

Wait and count to 5. → Point to the lesson’s diagram, kit or source. → Ask: What is done, and what is the next step? → Model one step, then return the next step to the pupil. → Finish one example together, then fade the help. No physical prompt. Stage scripts: I do “Watch: one thing changes; I keep the other parts the same.”; We do “Which control is already on the plan? What is still missing?”; Independent “Point to your result. What did you measure without my help?”

At Independent, one adult works with supported pupils, the other holds the group; choose roles at the start and swap across the week. If only one adult attends, use the actual staffing plan. At Exit, hand off the deepest prompt level and what was independent.

**Cold-call / invite bank, answers:**
- F: What is our changed factor? → Surface type.; What do we measure? → Distance travelled.
- M: Why keep the same toy? → So toy differences do not affect comparison.; Why use the same launch? → A stronger push could change distance.
- H: What does a repeat help you check? → Whether results are similar under the same conditions.; If repeats disagree, what is a fair response? → Keep the results, check method and repeat; do not alter data.

**Regulation:** Agree a quiet pause signal and supervised place. Check in before hinge and Independent; point to the last completed step on re-entry. No evidence while a pupil is distressed.
