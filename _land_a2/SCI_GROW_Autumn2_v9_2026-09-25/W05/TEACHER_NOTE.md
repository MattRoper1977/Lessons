## Hinge and decision

**Question:** A model trolley stops sooner on a mat than on a smooth board. Which idea is relevant to test?

| Option | Correct? | Diagnosis |
|---|---|---|
| The length of Earth’s orbit. | no | Transfers a space model to a surface-and-motion question. |
| Friction at the trolley surface. | yes | Uses the new case accurately. |
| The amount of daylight outside. | no | Uses daylight rather than the changed surface to explain the trolley run. |
| The climate of the whole Earth. | no | Uses a whole-Earth climate pattern for a local trolley test. |

**Rule:** About 3 in 4 or more right → move on. Otherwise re-model with the named I-do example, then ask the parallel hinge. **Parallel:** A block is pulled over two surfaces. Which idea helps test why the pull differs: friction or Earth’s rotation? Answer: friction.

**Misconceptions:**

| Misconception | Spot | Correct |
|---|---|---|
| Any science model can answer any question. | Pupil chooses A, a space model for trolley motion. | Match the model’s observable feature to the question before making a claim. |
| One different toy run proves roughness alone caused it. | Pupil chooses B correctly but then claims one run proves the cause without controls. | Repeat runs with a consistent start and push before treating the difference as strong evidence. |


**AQA Entry Level Science style bridge (classroom planning):** Choose a suitable model and describe the observation that supports a claim. This is a planning bridge, not a claimed unit outcome or code.

**Feedback codes:** VF · WS · I · NS(+) · E · R · // · ?. At We do 2, record WS or I and actual prompt level; at Review, VF and specific NS(+); at Exit, one self-edit // or read back ?. R means a response to the next step heard by an adult in the next lesson, never auto-awarded. E: evidence captured on the school's evidence app only if an observable curriculum action occurred, never while distressed. The page stores no response. Pathways: high support with VF/WS; Build: mix of WS/I; Grow: mostly I and self-edit; Launch: independent self-assessment.

## Adults, regulation and prompt ladder

Wait and count to 5. → Point to the lesson’s diagram, kit or source. → Ask: What is done, and what is the next step? → Model one step, then return the next step to the pupil. → Finish one example together, then fade the help. No physical prompt. Stage scripts: I do “Listen: first I read the question, then choose the matching kit.”; We do “Which model is already chosen? What observation is missing?”; Independent “Show me your claim; which clue did you find on your own?”

At Independent, one adult works with supported pupils, the other holds the group; choose roles at the start and swap across the week. If only one adult attends, use the actual staffing plan. At Exit, hand off the deepest prompt level and what was independent.

**Cold-call / invite bank, answers:**
- F: Which kit is for a motion question? → Toy and surface.; Which kit is for day and night? → Torch and ball.
- M: Why do we name a clue? → It supports the claim.; Why is one toy run weak evidence? → The start or push might have changed.
- H: What can the torch-and-ball model not show exactly? → True size and distance, among other details.; Why does a warming card not show a local force? → It represents a long-term causal chain, not the toy’s motion.

**Regulation:** Agree a quiet pause signal and supervised place. Check in before hinge and Independent; point to the last completed step on re-entry. No evidence while a pupil is distressed.
