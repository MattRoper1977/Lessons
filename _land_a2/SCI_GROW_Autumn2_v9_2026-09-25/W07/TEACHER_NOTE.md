## Hinge and decision

**Question:** A new question asks why a model sled stops sooner on a mat. Which kit can help test it?

| Option | Correct? | Diagnosis |
|---|---|---|
| Sled and two marked surfaces. | yes | Uses the new case accurately. |
| A torch and turning globe. | no | Uses a rotation model to answer a friction question. |
| Two ice cubes on dark card. | no | Uses melting ice rather than a moving sled to test the surface effect. |
| A weather report from today. | no | Uses a single weather report instead of a surface-and-motion test. |

**Rule:** About 3 in 4 or more right → move on. Otherwise re-model with the named I-do example, then ask the parallel hinge. **Parallel:** A new place on a globe turns into shade. Which kit explains that: globe and fixed lamp, or sled and mat? Answer: globe and fixed lamp.

**Misconceptions:**

| Misconception | Spot | Correct |
|---|---|---|
| A melting-ice model tests why a moving sled stops on a surface. | Pupil chooses C, an ice model for sled motion. | Use the sled with two marked surfaces for the process in the question. |
| One day’s weather report can explain the sled’s stopping distance. | Pupil chooses D, using one day’s weather to explain the sled. | Observe and compare the sled on surfaces instead of using unrelated weather. |


**AQA Entry Level Science style bridge (classroom planning):** Use a suitable model to explain a science idea with a matching clue. This is a planning bridge, not a claimed unit outcome or code.

**Feedback codes:** VF · WS · I · NS(+) · E · R · // · ?. At We do 2, record WS or I and actual prompt level; at Review, VF and specific NS(+); at Exit, one self-edit // or read back ?. R means a response to the next step heard by an adult in the next lesson, never auto-awarded. E: evidence captured on the school's evidence app only if an observable curriculum action occurred, never while distressed. The page stores no response. Pathways: high support with VF/WS; Build: mix of WS/I; Grow: mostly I and self-edit; Launch: independent self-assessment.

## Adults, regulation and prompt ladder

Wait and count to 5. → Point to the lesson’s diagram, kit or source. → Ask: What is done, and what is the next step? → Model one step, then return the next step to the pupil. → Finish one example together, then fade the help. No physical prompt. Stage scripts: I do “Watch me select one model for this question.”; We do “What is supplied? Which observed clue is missing?”; Independent “Choose your own question. Which clue can you show without my prompt?”

At Independent, one adult works with supported pupils, the other holds the group; choose roles at the start and swap across the week. If only one adult attends, use the actual staffing plan. At Exit, hand off the deepest prompt level and what was independent.

**Cold-call / invite bank, answers:**
- F: Which model fits day and night? → Torch and ball.; Which model fits toy motion? → Toy and surface.
- M: What makes a clue useful? → It matches the question and claim.; How can you show a force result? → Point to or name an observed toy run, with controls noted.
- H: What is one limit of a torch-and-ball model? → It is not to scale, among other limits.; What would strengthen a climate claim? → Long-term observations, not one weather report.

**Regulation:** Agree a quiet pause signal and supervised place. Check in before hinge and Independent; point to the last completed step on re-entry. No evidence while a pupil is distressed.

## Prepared model handling · practical safety

**Kit:** Adult-prepared familiar model kit for the selected question

**Method:** Use only the prepared model selected for the agreed practice or formal task.

**Pupil Risk:** Loose model parts, a toy launch or a torch beam could cause harm if misused.

**Pupil Safe:** Keep model parts on the tray, launch only with adult permission and aim a torch away from eyes.
