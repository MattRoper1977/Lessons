TEACHING
40 minutes; a pair. Continue the two-level maze project for the unit award using fictional project card A or B. Each pupil creates two named score variables, attaches two set-to-zero blocks directly under the start event, and places both stage readouts clear of the maze walls. A partner tests the start reset from a non-zero value and suggests one useful improvement. Save, close and reopen the individual file in ICT_Practice/W01_Variables as Maze_Score_A_v1 or Maze_Score_B_v1, retaining the extension supplied by the software. Shared-device roles change after six minutes. Supported has a variable-and-reset frame; Independent builds from the project card; Aspire adds a round counter initialised to 1 and saves a separate v2. Paper work is rehearsal, not proof of digital variable setup or saving. Keep real personal details out. Do not publish pupils' files.
