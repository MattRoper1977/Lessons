TEACHING
40 minutes; a pair. Continue the two-level maze project for the unit award using fictional project card A or B. Each pupil adds a pickup contact rule that changes the pickup variable by 1 and a hazard contact rule that changes the hazard variable by 1 and returns the player to the start pad, while keeping both set-to-zero blocks on the start event. A partner tests both events and the start reset. Save, close and reopen the individual file in ICT_Practice/W02_Events as Maze_Events_A_v1 or Maze_Events_B_v1, retaining the extension supplied by the software. Shared-device roles change after six minutes. Supported has a two-event scoring frame; Independent builds from the project card; Aspire adds a finish gate bonus event (+5) and saves a separate v2. Paper work is rehearsal, not proof of digital event building or saving. Keep real personal details out. Do not publish pupils' files.
