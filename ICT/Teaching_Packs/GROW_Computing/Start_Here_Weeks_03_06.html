Before teaching

Load the chosen .sb3 file in Scratch using File → Load from your computer. The HTML activities work offline; the Scratch website needs internet access. An installed Scratch app can open .sb3 files offline.

Pupils save their own .sb3 project each week. Download any typed HTML responses before closing the activity; those text files are separate from the Scratch project.

Weeks 3–6 focus on outcomes 1–4. Gameplay complexity and full testing remain in Weeks 7–8. Agree additional construction time in advance where the Week 6 review shows it is needed.
