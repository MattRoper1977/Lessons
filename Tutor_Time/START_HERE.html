British Values · Behaviour Focus · KCSIE

Eight front-of-class whiteboard sessions: the fundamental British Values (W1–4), our Behaviour Focus code and restorative repair (W5–6), and protective KCSIE sessions (W7–8) — each with a live interactive moment, a Lundy loop the class actually feels, a pass-allowed check-out, and a pupil-run evidence slot.

How a deck runs: 9 slides — title & settle → two sparks → an everyone-plays interactive (live vote / sort / builder, click-only, no timers) → the talk (Standard/Supported toggle) → the Lundy loop as a real class moment → check-out (pass allowed) → the evidence slot (Evidence Captain + caption frame + launch extension) → next-week hook. Arrow keys or ▶ to advance; Calm mode in the bar.
