# BUILD Humanities Teesside v3 — teacher guide

## Core lesson grammar
Arrival → Starter → I Do → We Do → I Do 2 → We Do 2 → Independent historian evidence → Exit/Influence.
Every core route is exactly 40 minutes.

## Connected journey
PLACE IN TIME → READ THE SOURCE → WHY THEY CAME → WHO MATTERS → BIG DEAL? → PLAN THE STORY → TELL THE STORY → MAP THE MOVEMENT & INFLUENCE.

## Source rule
An unattributed item is not ready for source work. Every genuine source needs:
- what it is;
- who made it;
- when;
- where it came from;
- rights/permitted use.

Accessible source versions are part of the planned source pack. A format/access barrier must not be misread as poor historical understanding.

## Lundy / interpretation
Humanities keeps the existing BUILD closure. No second receipt, initial, queue, tracker or day-close routine is added.
The general interpretation instrument remains `LundyLoop/5_staff_training/Reading_the_Response_Card.html`.
Humanities-specific prompts are examples only: shows-vs-inference confusion, bias-means-useless misconception, source-density barrier, missing provenance.

## Care
- No community is reduced to a single story.
- Personal/family migration or family-source disclosure is never required.
- General, historical and local routes count equally.
- Private pupil/family material is not automatically a classroom source.

## Evidence
Historical decision → evidence/clue/source/map → pupil explanation, limitation or uncertainty.
