# Artist and reference-image provenance guide

The source BUILD Art Scheme of Work explicitly requires locally approved, credited Teesside reference images and verified practitioner/organisation sources before teaching.

For v3:

1. Do not add an artist image because it looks relevant.
2. Confirm the artist/maker/organisation identity and source.
3. Record creator, title/work description where known, source/provider and licence/permission basis.
4. Keep factual context separate from pupil interpretation.
5. In W2, analyse what is visible before giving biography/context.
6. Do not imply an organisation endorses the lesson or Made by Matt.
7. If a reference cannot be verified or appropriately used, replace it with another reference; do not invent missing facts.
8. Pupil work/photos follow the school’s consent, safeguarding and evidence rules.

The W2 v3 HTML can load a teacher-approved local image with FileReader. It stays in the current browser page only and is not uploaded or saved by the lesson.
