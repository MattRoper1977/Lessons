# Lesson packs

One zip per lesson, linked from the lesson's own page on the Made by Matt lessons site
("Download the whole lesson pack").

Each zip holds the slides (PDF and editable slide file), the teacher and TA plan, task cards,
arrival and exit sheets, book stickers and an offline copy of the lesson.

Files here keep their names for good so links never break. New packs are added; existing ones are not renamed.
