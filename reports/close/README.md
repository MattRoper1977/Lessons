# Session closes

One file per session. `SESSION_CLOSE.md` was a single path, which meant two
sessions closing on the same day collided on it — and a third would have collided
again. Per-session filenames make that structural rather than a matter of care.

| date | session | file |
|---|---|---|
| 2026-08-01 | BUILD/GROW convergence | [`2026-08-01-convergence.md`](2026-08-01-convergence.md) |
| 2026-08-01 | gate & instrument census | [`2026-08-01-gate-census.md`](2026-08-01-gate-census.md) |

The rules the estate has earned live in `LundyLoop/tools/INSTRUMENTS.md`, not here.
The audited instrument inventory and the named backlog live in
[`../INSTRUMENT_INDEX.md`](../INSTRUMENT_INDEX.md).
