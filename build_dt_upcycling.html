Teesside Community Upcycling

A six-week BUILD Vocational/D&T unit · Autumn 1 · SEMH alternative provision

What these resources are for: pupils turn reclaimed timber (pallets) into real community assets — modular planters or wildlife boxes for a local green space. Every cut, measurement and join becomes photographic ASDAN portfolio evidence, so reluctant writers build a qualification through making, not paperwork.

ARRIVAL2×2 recap + a settling wordsearch (no crosswords) to build vocational vocabulary.
▣ MODELI do / we do: visual knowledge organiser + safe tool handling.
◆ INDEPENDENTYou do: differentiated Standard or Supported task (toggle in each pack).
EVIDENCEDocumentarian photos, annotated visuals, witness shorthand → ASDAN tracker.

The launch-level evidence engine

Embedded in every pack so practical work becomes portfolio evidence without essays: a rotating Documentarian photographs the build (Lundy Voice); photos print onto portfolio sheets for sharp annotations; and pre-printed witness-statement shorthand lets staff tick the exact ASDAN/Lundy competency, sign, and bank it instantly.

SEMH-safe throughout: calm palette, reduced-motion, Calm Mode, and task zones marked by icon + label + colour (never colour alone). Built for accessibility.
