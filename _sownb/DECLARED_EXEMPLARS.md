# Declared worked exemplars

This file is the explicit register for invented people used in worked examples.
It must contain invented exemplars only; real pupil or staff records must never be
copied here. One exemplar is written per bullet as `- Full Name`.

There are no declared worked-exemplar people in the RSH2 batch.

## Classes ruled on 2026-09-02 (ORDER VB-RUN11F, NAMES g10)

- **Public figures.** A dead or nationally notable public figure relevant to
  the cell may be named in a lesson (the reviewed register is
  `_sownb/feb/PUBLIC_FIGURES.md`). A living local individual is never named:
  a role label stands in ("the lifeboat coxswain", "a local councillor").
- **Places.** A capitalised pair that names a place is a PLACE, never a person,
  and resolves through `_sownb/PLACES.md`. A place never holds a lesson.

This register still declares no invented exemplar people.
