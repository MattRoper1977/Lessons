# BASELINE — visuals and "we do" variety

Measured 2026-09-01, run 6. **Report only. Nothing was changed.** This is what the estate actually looks like today, so the standard can be written from the estate rather than imagined.

## Visuals: the estate is almost entirely text

350 live lessons measured. A visual counts as **explanatory** only if it has at least three text labels, is bigger than an icon, sits in a teaching stage, and the prose of that stage actually refers to it. A diagram nobody mentions is decoration.

**180 lessons — 51% — have zero explanatory visuals. The estate median is 0. The most any lesson has is 2.**

Nothing is print-dead, because there is almost nothing to kill.

## "We do": three types carry it, and one family repeats itself twelve times

Only **56** of the 350 lessons have a stage actually titled "We Do". In those, nine activity types appear — but the distribution is very top-heavy:

| type | uses |
|---|---:|
| label-the-diagram | 63 |
| sort-or-match | 56 |
| decision-lab (choose and justify) | 48 |
| *unclassified* | 18 |
| rank-or-order | 15 |
| show-me / everyone commits | 6 |
| predict-then-check | 3 |
| spot-the-error | 1 |
| paired-talk | 1 |

Three types carry roughly 85% of everything. **BUILD ASDAN runs twelve consecutive lessons with an identical activity type-set** — the longest monotony run in the estate. Every other family stays at one or two.

The 18 unclassified stages are not noise: most are the "everyone commits" pattern (a whole-class show-me before the answer is revealed) and "choose, then justify". Both are real types the tool had not been told about.

## Proposed six-type rotation — FOR YOUR CONFIRMATION

Built from what is there plus what is conspicuously missing.

1. **commit-and-reveal** — everyone shows an answer at once, then it is revealed. *Best example: SCI_B_W14A Autumn Science Review.*
2. **sort-or-match** — put items into groups or pair them up. *BUILD_ASDAN_A2_CON_W4.*
3. **label-or-annotate** — add labels to a diagram, map or image. *GROW Science v3 Friction.*
4. **sequence-or-rank** — put steps in order, or rank by a criterion. *BUILD_ASDAN_A2_PFA_W3.*
5. **predict-then-check** — commit to a prediction before testing it. *SCI_L_W14L2.* **Only 3 uses in the whole estate.**
6. **spot-the-error** — find and correct a deliberate mistake in a worked model. *BUILD_ASDAN_A2_CON_W2.* **Only 1 use in the whole estate.**

**Decision-lab (choose and justify) is deliberately not in the six.** It is already the estate's most-used pattern and the rotation exists to break its grip; it stays as the default shape for the independent stage, where it belongs.

Word-load note, since the overloads came from reading stages: every type currently spans roughly 1,010 to 3,463 pupil words. The type does not predict the load — the two heaviest examples of four different types are the same two overloaded Humanities lessons.
