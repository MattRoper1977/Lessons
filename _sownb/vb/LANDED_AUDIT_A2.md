## The three regressions

### R1 — the pupil-content measurement was blind to 43% of the estate

**Severity: this is the finding of the audit.** `g18`, `g23`, `g24` and `g25` all
selected teaching stages with

    //main[contains(@class,"deck")]/section[contains(@class,"slide")]

which describes the n6 shell only. The classic chassis puts its stages in
`main.deck > div.slide-container > div.slide`. Across the estate:

    deck-shaped HTML files                            607
      n6 shell                                        343
      classic shell                                   264   ← measured as ZERO

On main, before this order:

    BUILD_HUM_W16_Then_And_Now_And_What_Is_Fair.html   0w  x0.0  WITHIN  ceiling PASS

on a deck carrying ten stages and 2,159 pupil words. `g25` on the same deck read
`weDoStages=0` and RED'd with "deck has no we-do stage to corroborate the
declaration" — a gate failing for want of an instrument.

This is not new to the window, but **#271 walked a VB deck into it**: BUILD_HUM_W16
was n6 and measurable before the reshell and unmeasurable after.

Under the corrected instrument the same deck reads **2,159w, family median 1,412,
x1.53, HEAVY, ceiling RED**.

**Repair: this order's own gate PR.** Not a revert — the deck is fine, the
instrument was not.

### R2 — the reshell has never carried declared stage timings

`BUILD_HUM_W16` before #271 carried nine `data-min` values summing to exactly 40:

    [0, 3, 3, 4, 3, 3, 4, 16, 4]  → 40

After #271 it carries none. Nothing noticed for a fortnight because the only
reader of `data-min` was the same n6-shaped XPath that already returned nothing
on a classic deck — R1 hid R2. A lesson that does not say how its forty minutes
are spent cannot be picked up by a cover teacher, which is what the pack is for.

**The scale is larger than one deck.** Running the classic-v2 contract across
every deck the recipe produced — identified by the two things only it emits, the
target TA modal and a print area — gives 54 decks, all Humanities:

    54 recipe-shaped decks
      54/54  stage-timings-carried   RED
      24/54  own-lesson-config-only  RED
      24/54  lundy-in-three-places   RED

So the recipe never carried stage minutes. #271 did not introduce the defect; it
made it visible, by reshelling a deck that *had* forty declared minutes into one
that had none. Every other recipe-produced deck was authored without them from
the start, and no instrument in the estate could see it.

**Repair:** the recipe now carries the minutes forward and asserts the sum
survives (`reshell_classic_v2.py`, control
`stage-timings-carried-and-sum-preserved`), and the contract clause
`stage-timings-carried` reds any deck that lacks them. **54 landed decks still
need their timings — a lesson-PR backlog, not this PR. It is in the resume
block, and CI prints the distribution on every run so it can be worked down.**

### R3 — the reshelled deck's screen visuals are print-dead

`g24` on the landed BUILD_HUM_W16 now reports `explanatory=2 printDead=2 RED`.
The classic chassis hides the whole slide container under `@media print`:

    @media print{ … .slide-container{display:none!important} … }

so every diagram a pupil sees on the board is absent from the paper pack. The
contract row `visuals.explanatory.min` carries `printSafe: true`, so this is a
contract red, not a preference. #271 recorded g24 as PASS because the old gate
never resolved print visibility at all.

**Repair:** flagged, not fixed here. Fixing it means authoring print-safe
figures into the print pack, which is a lesson change. In the resume block.

week of the workbook cell it cites — deliberately, as a red control. Across the
estate:

| shell | week agreement | count |
|---|---|---|
| classic | agrees | 30 |
| classic | disagrees by +1 | 4 |
| n6 | disagrees by +1 | 15 |

is a no-op; and every n6 deck with a resolvable config is refused. The offset is
exactly +1 in all 19 disagreements, and every one is a week-14/15/16 deck — the
`lesson-config` `week` field is a filename-era label that the run-11 spine re-key
left behind, exactly the drift §0.6 exists to rule on.

This blocks §5.2 as written. **Do not fix it by relaxing the recipe's check.**
The check is right and it is catching 19 stale labels. In the resume block.
