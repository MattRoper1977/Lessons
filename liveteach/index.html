Live-Teach Projector Kit

A projector view for the class, an optional teacher window for you, and one set of keys that drives both.

Open

📽 Projector viewOpen this on the screen the class sees. Complete on its own — every control is on it. 🧑‍🏫 Teacher HUDOptional second window for your screen. Mirrors and drives the projector.

Which setup am I in?

One screen (or you're not sure): just open the projector view. The control strip at the bottom (move the mouse to wake it) and the number keys do everything. A USB clicker plugged into the PC works too.

Two screens (extended desktop): press Windows key + P on the classroom PC and pick Extend. Drag the projector view onto the projector screen, keep the teacher HUD on yours. Both windows must be in the same browser on the same PC — that's how they talk; nothing leaves the machine.

Keys (both windows)

  1. Space — pause / resume the sim
  2. 1 / 2 / 3 — timers: 1, 3 and 5 minutes
  3. 0 — clear every overlay
  4. H — hint on / off  ·  P — show-of-hands poll
  5. Esc — close whatever is on top
