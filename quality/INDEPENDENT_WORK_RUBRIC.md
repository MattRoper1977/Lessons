# Independent work and challenge rubric

> **Source: SEMH audit 2026-08-04, adapted.** Derived from audit document 08
> (`08_INDEPENDENT_WORK_AND_CHALLENGE_RUBRIC.md`). Estate adaptations marked **[estate]**.

## Independence scale

| Level | Observable learner ownership | Adult / scaffold position |
|---|---|---|
| 0 — Adult product | Adult selects, sequences or explains; learner mainly copies, agrees or decorates. | Continuous direction or completion. |
| 1 — Directed choice | Learner chooses between tightly controlled options, one step at a time. | Frequent specific prompts. |
| 2 — Supported sequence | Learner follows a known process, makes some decisions using a model/checklist. | Intermittent prompts; scaffold visible. |
| 3 — Independent execution | Learner plans/executes the familiar task, checks progress, asks targeted help. | Reference materials available; no continuous direction. |
| 4 — Transfer and adaptation | Learner applies learning in a new context, changes strategy after feedback, justifies decisions. | Adult as audience/coach, not co-author. |
| 5 — Sustained authorship | Learner defines or refines the problem, manages constraints, produces, evaluates, sets a next step. | Access arrangements remain; content/decision prompts minimal. |

Do not infer independence from handwriting, silence, time on task or the absence of an
adult. Record the evidence.

## Prompt codes

| code | meaning |
|---|---|
| `WT` | wait time |
| `SP` | pupil self-prompt / reference |
| `VC` | visual cue |
| `GV` | general verbal prompt |
| `SV` | specific verbal prompt |
| `MO` | model / example revisited |
| `SC` | scribe / access support only |
| `DS` | direct solution or step supplied |

Record: **highest prompt used · decision(s) made by the learner · what can be removed next
time · access arrangement that should remain.**

### [estate] How this may and may not be recorded

This rubric describes a **paper/TA-side** record. It is bound by rulings that predate
the audit and outrank it:

- **Paper is primary**, not a fallback. **No pupil words persist on the device.**
- **The record is never counted or aggregated.** "Watch for the first spreadsheet" is a
  named register check. A prompt code is a next-step aid, not a metric.
- **The adult is a witness and next-step-giver, never a signatory.** `SC` in particular
  records access support given; it is not a countersignature.
- **A wrong prediction is never coded as failure.**
- It must not become a register, a score, or a second copy of the existing loop.

An architecture already ships for the surrounding behaviour: the **LL-G modality strip**
(`ll-g:loop-mark v1`, 45 BUILD lessons, printed beside *"Pupil response — my next step"*)
and the **written closure line** *"What I said, and what it changed"* (48 GROW/LAUNCH
lessons). Anything built from this rubric **extends** those; it never duplicates them.
The strip must remain byte-identical in print-feedback.

## Challenge-quality test

A task becomes harder through one or more of:

1. **Conceptual complexity** — more relationships, abstraction or explanation.
2. **Transfer** — a new context, audience, material or problem.
3. **Uncertainty** — incomplete or conflicting evidence; more than one defensible route.
4. **Independence** — fewer content prompts while access remains.
5. **Precision** — better measurement, vocabulary, evidence or reasoning.
6. **Consequence** — authentic audience, product, decision or leadership.

"More writing", "more boxes", "finish faster" and "use a harder label" do not by
themselves increase challenge.

## Pathway map

### BUILD
identify and select · sort/classify · sequence · demonstrate a safe process · give one
relevant reason · complete an authentic product with reducing prompts · recognise a
mistake and make one correction.

A strong BUILD stretch asks the pupil to **transfer one idea** or **explain why their
choice works**.

### GROW
explain cause/process · compare and rank · apply to a new but related context · control
variables or work within constraints · justify with evidence · monitor and adjust ·
distinguish a main factor from a contributing factor.

A strong GROW stretch introduces a **constraint, counterexample, alternative
interpretation or validity judgement**.

### LAUNCH
infer and evaluate · synthesise multiple sources · plan and execute a sustained outcome ·
transfer to an unfamiliar context · explain limitations and trade-offs · lead, delegate,
pilot and adapt · review impact and specify next action.

LAUNCH retains reading, sensory, motor and navigation support. Reduced scaffolding
targets the **thinking**, not access.

## Grade and qualification guardrail

Pathway demand is not a grade prediction. Task language may be "Entry-level demand",
"Level 1-style skill" or "GCSE Foundation bridge" **only** where the distinction is
explicit and the specification is current. Certification requires the registered
qualification and its assessment process.

**[estate]** Tiers are **Supported / Standard / Stretch**. Arts Award carries **no GCSE
AO1–AO4, no grade bands and no hours threshold** — TQT is guidance only.
