DEPLOYING THE LUNDY LOOP PACK TO GITHUB PAGES
Matt Roper · target URL: https://mattroper1977.github.io/Lessons/LundyLoop/

WHAT THIS BUNDLE IS
A web-safe copy of Master Pack v3.1 in a folder named LundyLoop (no spaces in any path,
so every URL works). Identical content to the zip pack.

STEPS (5 minutes, same as your Games folders)
1. In your GitHub repo that serves mattroper1977.github.io, open the Lessons folder
   (the one that already contains Games/).
2. Upload the whole LundyLoop folder alongside it: Add file -> Upload files -> drag the
   LundyLoop folder in -> Commit.
3. Wait a minute for Pages to rebuild, then test:
   https://mattroper1977.github.io/Lessons/LundyLoop/index.html
4. Share that one link with staff. Every document, the calibration game and the
   Loop Walk Logger are reachable from it. The logger works per-device: each phone
   or Chromebook keeps its own log in the browser (nothing is sent anywhere).

THE QR CODES
Every poster in 6_posters carries a QR footer pointing at its subject guide at the URL
above. Deploy BEFORE printing posters, then scan one to check. If you ever host the
pack at a different path, tell Claude and the posters can be re-stamped in minutes.

PRIVACY NOTES FOR HOSTING
- This web copy has been scrubbed: it contains NO pupil names anywhere (verified).
  The Loop Passports here are blank write-in templates, and the Ofsted/INSET sheets
  use neutral phrasing. The NAMED passports for the current roster exist only in the
  private Master Pack zip -- keep that on school systems, never on GitHub.
- COMPLETED passports and any exported QA CSVs must never be uploaded: school
  systems only. GitHub Pages is public.
