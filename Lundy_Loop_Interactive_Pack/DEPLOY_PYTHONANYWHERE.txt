1. Upload this bundle's LundyLoop folder to PythonAnywhere, e.g. to
   /home/MattRoper1977/LundyLoop  (Files tab -> upload the zip -> open a Bash
   console -> unzip it there).
2. Web tab -> your existing web app -> scroll to "Static files".
3. Add a mapping:   URL: /lundy/    Directory: /home/MattRoper1977/LundyLoop/
4. Reload the web app. The pack is live at:
   https://mattroper1977.pythonanywhere.com/lundy/index.html
   This sits happily alongside your Progress Classroom Flask hub — static
   mappings are served before Flask routes, so nothing in the hub changes.

OPTION B — FLASK ROUTE (only if you want it inside the Flask app itself)
Use the included flask_app.py as a reference: copy the two routes into your
existing Progress Classroom app (adjusting BASE to where LundyLoop lives) and
reload. Option A is simpler and faster; use B only if you want to add logic
later (e.g. a teacher-code gate like your 5543 pattern).
