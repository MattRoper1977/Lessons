What colour does phenolphthalein turn in an alkaline solution?

Bright pink. (Colourless in acid.)

3. UI advantage

State one advantage of universal indicator over litmus.

UI shows a range of colours — you can estimate the pH, not just whether it's acid or alkali.

4. Lead-in 🔬

Lemon juice and stomach acid are both acids. Are they equally acidic? How could we measure the difference?

No — stomach acid is much stronger. We can use the pH scale (0–14) to measure how acidic or alkaline something is — that's today's lesson.

1. Compare litmus

State one advantage AND one limitation of using litmus paper.

Advantage: quick / simple to use. Limitation: only tells you acid or alkali — gives no information about strength.

2. Methyl orange

What colour does methyl orange turn in: (a) an acid? (b) an alkali?

(a) Red.   (b) Yellow.

3. Why choose UI?

Why might a scientist choose universal indicator over litmus when testing an unknown solution?

UI gives an approximate pH via a range of colours, not just acid/alkali — this shows the strength of the acid or alkali too.

4. Lead-in 🔬

Lemon juice and stomach acid both turn UI red. Does that mean they have exactly the same pH? Explain your answer.

No. UI groups several pH values into "red" (pH 0–2). The actual pH could differ. We need a more precise scale (the pH scale, 0–14) — and ideally a pH meter — to tell them apart.

📋 The 5 Classifications (learn these!)

• Strongly acidic: pH 0–3  e.g. battery acid, stomach acid, lemon juice

• Weakly acidic: pH 4–6  e.g. coffee, rainwater, milk

• Neutral: pH 7  e.g. pure water

• Weakly alkaline: pH 8–10  e.g. baking soda, toothpaste, sea water

• Strongly alkaline: pH 11–14  e.g. bleach, oven cleaner

🧠 Memory Hook + Examiner Trap

"Acids Attack — Alkalis Are Above"

• Acid → low numbers (0–6)

• 7 = neutral (the ceasefire 🤝)

• Alkali above 7 (8–14)

⚠️ Examiner trap: Never write "a bit acidic" — always write weakly acidic or strongly acidic. The five exact words win marks.

💡 Real world: Lower pH = more acidic = more dangerous to handle. Higher pH = more alkaline = also dangerous (bleach, oven cleaner can burn skin).

I Do: Measuring pH with Universal Indicator (Spec 2.30)

Key Idea: Add UI → observe colour → compare to colour chart → read approximate pH → classify.

📝 The 5-Step Method

1. Add a few drops of UI to the solution.

2. Observe the colour that appears.

3. Compare to a pH colour chart.

4. Read the approximate pH.

5. Classify (strongly/weakly acidic, neutral, weakly/strongly alkaline).

💡 Key word: "Approximate" — UI gives an estimate, not an exact reading. Two main reasons: (1) colours between values are hard to read; (2) colour matching is subjective.
🌟 More precise alternative: A pH meter — an electronic probe — gives a precise numerical pH (e.g. 6.83). Used in industry, labs, and research.

pH ScaleRuns from 0 (most acidic) to 14 (most alkaline). Measures how acidic or alkaline a solution is. pH 7 is neutral.

Weakly acidicpH 4–6. Examples: tomato juice, black coffee, rainwater, milk (pH ~6).

Method – using UI to find pH (Spec 2.30):

  2. Observe the colour produced.

How to Measure pH with Universal Indicator (Method)

1. Add a few drops of UI to the solution → 2. Observe the colour → 3. Compare to a UI colour chart → 4. Read off the approximate pH → 5. Classify (strongly/weakly acidic, neutral, weakly/strongly alkaline).

Limitations of UI: Only gives an approximate pH. Colours between values can be hard to distinguish (e.g. yellow-green = pH 6 OR pH 7?). Subjective: different people may read it differently. For a precise reading: use a pH meter.

🎯 Examiner trap: Never write "a bit acidic" — always use the exact phrase: strongly acidic, weakly acidic, neutral, weakly alkaline, strongly alkaline.

🧠 Memory aid: "Acids Attack (low pH) — Alkalis Are Above (high pH)." pH is like a temperature gauge: 0 = dangerously acidic, 7 = safe and neutral, 14 = dangerously alkaline.

📝 Exam Phrases (Higher)

• "Universal indicator gives the approximate pH because the colours between values overlap and are subjective to read."

• "A pH meter gives a precise numerical reading (e.g. 6.83) — more reliable than a colour match."

• "Both pH 9 and pH 10 are weakly alkaline, but the higher pH is more strongly alkaline, so it is more likely to irritate or damage skin."

• "Method for using UI: add UI → observe colour → compare to chart → read approximate pH → classify."
