Before We Start: Anion & Water Tests in 60 Seconds

New to this? Flame tests found the metal (the cation). Today we find the negative ion (the anion) — and test for water. (All on Side A of your bridge sheet.)

Each anion has its own test

A different reagent for each ion — and a colour change for water.

1. Halides (Cl⁻/Br⁻/I⁻): add dilute nitric acid, then silver nitrate → white / cream / yellow precipitate.
2. Sulfate: add dilute HCl, then barium chloride → white precipitate. Carbonate: add HCl → it fizzes (CO₂ → limewater milky).
3. Water: anhydrous copper sulfate goes from white → blue.
Whiteboards — 20 seconds: which reagent finds halides? Which ion makes a powder fizz? Then we go straight into the tests.

PROGRESS SCHOOLS I Do

I Do: The Anion Tests & the Water Test (2.48 & 2.49)

Key Idea: each negative ion has its own test. Acidify first, then add the reagent and read the result. Get the acid right and the marks follow.

🧪 Halides & Sulfate

Halides (Cl⁻, Br⁻, I⁻): add dilute nitric acid, then silver nitrate (AgNO₃).

Cl⁻
White ppt
Br⁻
Cream ppt
I⁻
Yellow ppt

Sulfate (SO₄²⁻): add dilute HCl, then barium chloride (BaCl₂) → white precipitate (BaSO₄).

🫧 Carbonate & 💧 Water

Carbonate (CO₃²⁻): add dilute HCl → it fizzes; bubble the gas through limewater → it turns milky (CO₂).

CO₃²⁻ + 2H⁺ → H₂O + CO₂

Water (2.49): add the liquid to anhydrous copper(II) sulfate (white) → it turns blue.

CuSO₄ (white) + 5H₂O → CuSO₄·5H₂O (blue)

🎯 Examiner trap: use NITRIC acid (not HCl) to acidify for halide tests. HCl adds Cl⁻ ions → a false white precipitate. Acidifying first also removes carbonate that could give a false positive.

🧠 Memory aid: down the halides the precipitate gets darker — White → Cream → Yellow. “Cloud → Butter → Yolk.”

Don’t write: add HCl then silver nitrate (halide test)

Write: add dilute NITRIC acid, then silver nitrate

HCl contains Cl⁻ — it would give a false white precipitate with silver nitrate.

Talk to your partner: which test uses nitric acid and which uses hydrochloric acid — and why does it matter? Be ready to run the lab next.

The halide colours

Cl⁻ = white, Br⁻ = cream, I⁻ = yellow. They get darker going down (White → Cream → Yellow).

Scaffolding Sheet – Higher (Grades 2–4)

Ionic equations (with state symbols)

Chloride: Ag⁺(aq) + Cl⁻(aq) → AgCl(s)

Sulfate: Ba²⁺(aq) + SO₄²⁻(aq) → BaSO₄(s)

Carbonate: CO₃²⁻ + 2H⁺ → H₂O + CO₂

Why nitric acid?

HCl contains Cl⁻ ions. With silver nitrate these give a false white precipitate. Nitric acid has no halide ions, so it does not interfere.

Identifying a full compound

Flame test → the cation (metal). Anion test → the anion. Combine both to name the compound, then write the precipitate\u2019s ionic equation.
