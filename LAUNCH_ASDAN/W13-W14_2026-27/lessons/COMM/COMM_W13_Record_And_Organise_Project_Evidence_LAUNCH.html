3 minArrival · retrieve

Start with what is real

Choose a private route: point to one real project record, show its approved locator, or mark NO RECORD YET. No explanation is required at the door.

Least prompt first

Wait → self-prompt → visual cue → general verbal → specific verbal → model → direct support. Record adult support separately.

Find

Look for the original file, dated note, approved photograph, plan, product record or other genuine item. Keep it where the school expects it to be stored. A copied thumbnail is not a stronger source than its original.

Label

Carry forward the real date, lesson or event reference and locator. Mark learner work, shared work and adult preparation separately. If ownership or permission is unclear, choose AWAITING AUTHORISED CHECK.

Hold the gap

Use NOT FOUND YET when the original cannot be located. Write the next locating action and the responsible school role. Do not recreate a missing record from memory or make a substitute look historical.

Quiet rehearsal: point to the source clue, then point to the status. Speaking is optional. The first useful decision is whether the record is real and locatable, not whether it looks polished.

What would count?

What makes a record usable later: a polished appearance, a clear source trail, or an adult remembering what happened? Explain one choice.

Think → choose → explain or point → keep the first response visible.
Worked example A · usable trail

A dated planning sheet carries its original folder locator. The learner contribution and adult setup note are different fields. This is an illustrative card, not a claim that a project event happened.

Worked example B · hold

An image has no confirmed date, source or permission status. It may be genuine, but the index must show AWAITING AUTHORISED CHECK until the responsible role confirms how it can be used.

Worked example C · reject rewrite

An adult remembers what was said but no learner wording was recorded. Keep an adult observation if appropriate. Do not reconstruct a quotation or convert the memory into first-person learner voice.

Checking question: Which example can another authorised person locate without guessing? Which needs a check? Which would become misleading if someone filled the gap with a confident sentence?

4 minI Do · model

Watch the decision trail

Locate the original approved record; do not create a replacement story.
Label when it was made, what it shows and who contributed what.
Separate learner meaning from adult preparation, access support, exact-word scribing and filing.
Step 1 · source

Read the original label before writing an index entry. Copy the factual locator accurately. If the date belongs to filing rather than the activity, label that difference.

Step 2 · contribution

Separate what the learner selected, made, explained or changed from shared work. Put adult preparation, prompting, exact-word scribing and filing in their own support note.

Step 3 · meaning and limit

State what the record can help show and what it cannot settle. A plan can show intention; it does not prove delivery. A product can show an output; it does not automatically prove impact.

Model check: The index sentence should allow a reviewer to trace the item, understand the contribution and see the gap. It must not award credit, reconstruct history or make an adult-owned decision.

3 minWe Do · choose

Choose, then justify

Choose what can be indexed now, what must be held for an authorised check and what must never be rewritten as learner voice.

Select 1, 2 or 3, then explain the evidence clue.
Index now

A genuine item has a clear original, date or time reference, learner contribution and approved locator. Record it as PRESENT, then explain its bounded connection to the project.

Hold for a check

The item may be genuine, but consent, ownership, source or storage status is unclear. Record AWAITING AUTHORISED CHECK and name the responsible role; do not hide the uncertainty.

Do not index as learner work

The only wording is an adult summary or the item has been recreated after the event. Keep any legitimate adult record accurately labelled, but never present it as learner authorship.

Reason aloud or point: identify the source clue, the authorship clue and the status clue. A different response mode changes access, not the truth standard.

3 minI Do 2 · test

Accuracy includes limits

Use PRESENT only when the original or approved locator can be found.
Use MISSING when no genuine record exists.
Use AWAITING AUTHORISED CHECK where consent, filing or status must be confirmed by the responsible role.
PRESENT

The approved original or locator can be found. The index records what it is, when it was made, whose contribution it contains and how it connects to the project.

MISSING

No genuine record exists or the expected activity did not occur. Keep the row open. Name a future ethical opportunity only if it is genuinely available; never backdate or stage it.

AWAITING AUTHORISED CHECK

A responsible role must confirm consent, status, location, filing or whether an item may be considered. The lesson records the question; it does not make the decision.

Boundary comparison: PRESENT describes a traceable record, not success. MISSING describes the evidence position, not the learner. AWAITING AUTHORISED CHECK keeps authority with the role that actually holds it.

Locate together

One person reads the neutral index heading. Another identifies the original or approved locator. If it cannot be found, stop at NOT FOUND YET rather than searching by invented detail.

Connect together

Use the project purpose already in the school-held material. Explain one bounded connection between the genuine item and that purpose. Do not add an outcome, criterion, level or qualification claim.

Limit together

State one missing field, perspective, permission, source clue or authorship distinction. Choose whether the row is PRESENT, MISSING or AWAITING AUTHORISED CHECK and explain why.

Rehearsal check: Can an authorised adult follow the locator? Is learner meaning separate from adult support? Does the status remain honest when the evidence looks impressive? What report-back is actually possible?

16 minIndependent · evidence

Make the evidence trail usable

Build a project evidence index from genuine school-held records. Record source/date, original locator, learner contribution, shared/adult support, project link and status. If the project event or record did not happen, keep the row missing and name the next ethical action; never backdate or stage a substitute.

▲ Standard

★ Stretch

Audit duplication, missing viewpoints and evidence limits; design an ethical next capture without staging or reconstructing anything.

Do not reconstruct

Never backdate, stage an event, invent a result or quotation, convert adult wording into learner voice, or turn this activity into an assessed claim.

Prepare the index

Use the school-held records, approved source list and a response route that allows pointing, sorting, writing, typing, signing or exact-word scribing. Preserve originals and work from locators.

Build each row

Record item, source/date, original locator, learner contribution and meaning, shared contribution, adult preparation or support, project connection, status and one honest next action.

Check before hand-forward

Remove duplication, not content. Keep genuine corrections, uncertainties and gaps. Confirm that no event, quotation, result, consent decision or learner voice has been invented or reconstructed.

Evidence link

Hand forward the exact locator and a bounded statement of what the record helps show. Keep the source and status beside the statement so it can be checked.

Honest limit
