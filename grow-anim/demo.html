GROW Animation Framework

Every lesson in the GROW suite is composed from the same teaching behaviours, so pupils learn the language of the interface as well as the science. Open this page first — everything below is live, and every snippet is copy-paste ready.

PHASE 1Motion language

Ten movements. Each means exactly one thing, in every subject, all year. Pupils are never taught this table — they absorb it, because it never changes. Print it and put it on the wall in week one.

PHASE 2SVG science library

Nothing is a picture; everything is layers. Every structure a teacher might want to draw, glow, fade, morph, trace or zoom on its own is its own layer. Click any asset to load it into the stage below.

PHASE 3Progressive reveal engine

Replaces “everything appears” with observe → notice → think → explain → label. The teacher presses ▶ Next and narrates the line the framework prints for them. Pupils cannot read ahead, because nothing has been written yet — the words arrive only once the picture has made the point.

PHASE 4Interactive “We Do” framework

Question → Prediction → Discussion → Animation → Explanation → Check. Each move unlocks the next, so the lesson pauses naturally and nobody skim-reads ahead of the class.

PHASE 5Scientific process animations

Instead of “heat transfers…”, pupils watch particles vibrate, energy spread and temperature rise. Every asset that describes a process carries an @process script.

PHASE 6Invisible science

Pupils cannot see forces, fields, particles, energy, pressure or current — so show them. Switch a layer on and nothing physical changes: they simply see more. That experience is the whole point, and it is why the scene is drawn once and never redrawn.

<div class="g-stage" data-grow-asset="forces"
     data-grow-overlays="force,friction,gravity,reaction,energy"></div>

PHASE 7Prediction mode

Every major animation stops and asks. The class discusses, the teacher reveals, the animation continues. Instead of passive watching, pupils think before every reveal. Written as one verb in the script: pause "What happens next?"

PHASE 8Dual representation

Real world on the left, scientific model on the right, driven by one script so they can never drift out of step. Pupils constantly connect the concrete to the abstract.

PHASE 9Retrieval animations

Not a quiz. The picture starts to build, stops, and waits for the class to say what comes next. It feels far more active than multiple choice, and it is faster to run.

PHASE 10Misconception engine

Rather than telling pupils they are wrong, the wrong idea is animated first — honestly, without sneering — and then the same scene is corrected in front of them. A pupil whose idea has never been taken seriously does not give it up.

PHASE 11Scientific storytelling

Question → Investigation → Discovery → Explanation → Application, instead of definition → example → question. The spine sits at the top of the lesson and lights up as the lesson moves, so pupils always know where they are in the story.

PHASE 12Premium polish

Soft lighting, depth, parallax, particle fields, camera pans and micro-interactions — not because they are pretty, but because they keep attention exactly where the teacher wants it. Everything here is opt-in and switches itself off under prefers-reduced-motion.

Authoring a script

One line = one press of ▶ Next. The optional beat prefix tells the teacher which of the five moves they are on.

[beat] verb targets + verb targets :: what the teacher says out loud

observe: show ground, person, box    :: Somebody pushing a box.
think:   pause "How many forces?"    :: Hold up fingers.
notice:  overlay force + pulse box   :: One. The push.
notice:  overlay friction            :: And a second one, pushing back.
explain: label push                  :: Four forces. They were always there.

Verbs. The ten: draw pop glow pulse fade morph flow shake bounce trace zoom. Supporting: show hide unglow hi unhi unfade only unpulse untrace unzoom spot unspot label unlabel tick cross think unthink note wait. Teaching: pause overlay unoverlay heat beat.

Targets. Part names, comma-separated. morph ice>water for a change. body#2 addresses the second panel of a rail or a dual stage.
