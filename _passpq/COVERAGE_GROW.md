## 2 · The spine, minimum-count and command-verb tests

- **plan → use (over the required period) → review.** The **PEQ strand alone cannot carry
  it**: six single lessons, one per skill, can model *creating* a plan and *reviewing*
  it, but cannot clock the extended *use*. GROW's design intends the **GCOMM + ENT project
  strands** to be that extended use (the "Delivering a Project" arc, "plan phase this term,
  delivery in Aut 2"). **This is a coherent architecture** — but it means **no single unit
  is fully evidenced inside the PEQ strand**; each depends on the project strands closing
  the "use" and "review" LOs. Map for whoever registers: PEQ W1–W6 = know + plan + review
  scaffold; GCOMM/ENT Aut1–Aut2 = the clocked use. **PARTIAL until the cross-strand banking
  is confirmed to actually land each unit's E-LOs in the Binder.**
- **The "≥10 hours" rule (§2).** As in BUILD, **0 occurrences** of "10 hours / minimum
  period" in the GROW strand. The extended arc *implies* it (a term-long project), but it
  is never surfaced as a requirement. Same §2-vs-Binder discrepancy (the Binder shows
  activity minutes/words, not hours). **UNDETERMINED — needs spec.**
- **Command-verb pitch.** The L1 spec verbs per §2 (Outline / Describe / Give examples of a
  range) are **absent** (0 occurrences); the Standard tier uses evidence-production "do"
  verbs (appropriate) plus **"Explain" (12×)**, which leans toward L2. The Stretch tier
  explicitly targets "L2 evidence standard" (design). **Verdict: pitch looks broadly
  L1-appropriate on the production tasks, but the discussion/exit prompts use "Explain"
  where L1 criteria say "Describe/Outline". Whether that over-pitches depends on the spec's
  per-criterion LO verbs — PARTIAL / verify.** Do **not** "fix" the Stretch tier's L2 reach.
- **The "Delivering a Project" mislabel.** GCOMM/ENT bank `PEQ L1 'Delivering a Project'`.
  **No such PEQ unit exists** (Binder has only the six core skills). The *activity* is fine;
  the *unit label* is NONEXISTENT (CoPE/AoPE naming). Tier-2 correction: relabel to the
  real units the project evidences (e.g. TmWkSk1 + ComSk1 + DecMkSk1), by code, per the
  Binder. → FINDINGS §B.
- **Evidence architecture.** Same strong witness/photo/annotation stack as BUILD, same two
  deltas: **no learner signature** and **per-activity not per-criterion** on the printed
  record (the Binder closes the per-criterion gap). Both protected — reported, not edited.

## 3 · Bottom line for GROW

GROW's PEQ strand is **the real thing, and the closest the estate comes to compliant PEQ
delivery** — correct product, correct level, correct Stretch design, backed by a correct
Binder. Its gaps are precise and fixable:
1. **WellbLe1 (Wellbeing) has no home** in the six weeks — a GAP in a claimed six-skill
   suite. New teaching or an explicit cross-strand banking route is needed (Tier 3).
2. **Each unit's "use/review" LOs depend on the GCOMM/ENT project strands**, which must be
   confirmed to actually bank into the Binder per unit (Tier 3 / process).
3. **"Delivering a Project"** is a NONEXISTENT unit label → relabel to real unit codes
   (Tier 2).
4. **Friendly unit labels** on staff-facing surfaces → reconcile to Binder codes (Tier 2).
5. **Learner signature + per-criterion record** deltas (shared with BUILD).
