Then and now evidence record

Original captioned teaching model made for this pack. It demonstrates the supplied reasoning; it is not historical footage, survivor testimony or a documentary. The full transcript and factual source credits are included.

Question: Write a careful comparison caption.

Evidence: C Photo enquiry: Use the paired local photographs supplied with this unit. Read the captions and dates. Point to one feature in each image before deciding what changed.

Think aloud: Both photographs show the bridge. I use the dates to establish then and later, and point to a visible feature before naming a change.

Check: Why retain the source caption? It identifies the evidence and helps check dates and claims.
