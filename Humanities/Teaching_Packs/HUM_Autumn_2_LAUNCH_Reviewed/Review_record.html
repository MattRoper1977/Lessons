LAUNCH_A2_W01 · Maps symbols and grid references

Outcome: Use maps OS symbols and grid references.

Assessment: F: map check and location/pattern question.

Shared activity: map — Compare the practice-map key with the linked OS symbol guide. Read eastings before northings and practise four-figure references.

Independent task: Identify the genuine OS abbreviations Sch, PO and FB using the supplied key. Locate three features on the separate practice map using grid references and direction. Answer one independent location or pattern question.
