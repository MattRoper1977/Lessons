# Constructed source label standard

## Required label

> **CONSTRUCTED TEACHING SOURCE — created for classroom practice. It is not an archival original.**

## Use when

- a quotation is invented to model a viewpoint;
- details from several sources are combined;
- a facsimile is recreated without being an exact transcription;
- a source is simplified beyond ordinary accessible formatting;
- a fictional character or scenario is used.

## Also state

- factual basis;
- what was adapted or invented;
- why it is being used;
- which historical skill is being rehearsed;
- that provenance claims about a real archive/author cannot be made from it.

## Do not

- attach a real archive name or reference to a composite;
- ask pupils to assess “bias” or provenance as though it were original;
- place constructed and archival sources together without visible distinction;
- use invented detail as evidence for a factual historical claim.
