# GROW_SU1_W03 · TA deployment brief

## EEF five-layer scaffolding key

**Self-scaffold → prompt → clue → model → correct.** Move down only when the pupil can't go on; move back up as soon as they can. Start by waiting, checking the pupil’s own attempt and using the existing visual, communication or reading aid. An access aid is not a content answer.

1. **Self-scaffold — watch for:** Checks a tally total against the plotted value. Let the pupil check the source, key, diagram or own work before speaking.
2. **Prompt — two open questions:** “What was the count rule?” “Where is the matching tally or graph value?” Pause after each; accept point, sign, AAC, speech or writing.
3. **Clue — two narrowed questions:** “Which tally marks give this total?” “Which location label belongs with that total?” Give one clue at a time and then step back.
4. **Model — one step only:** Show one first step: Pick one feature, location and tally rule; count the marks before describing a pattern. Then the pupil tries the next matching move with the source in view.
5. **Correct — one direct fact and when:** If the pupil still cannot continue after that model, give only “Same rule and named location” for “What makes a fieldwork count comparable?”. Then ask for a fresh application, record the level used and fade back toward self-scaffolding.

**Objective:** Carry out simple fieldwork about my local area.
