Opening

GROW · Humanities · Summer 1 · Week 2

Atlases grid references and digital maps

Learning goal

Use atlases grid references and digital maps.

How does our locality compare with other places?

I can locate places, use maps and grid references, collect observations, distinguish physical and human features and support a comparison with evidence.

40 minutes, with flexible pauses. Point, speak, draw, type or write. A fictional example is welcome.

Arrival task

Revisit earlier atlas and grid work. Start here if it is new: an atlas is a book of maps; the key explains symbols; read eastings across first, then northings up. The practice map already prints each reference.

Start with 1 and 2. Continue with 3 and 4 when ready.

Help

Maps.

Easting.

Help

4. What does a map key explain?

Help

The meanings of the symbols.

1. How can an atlas index help you?

Help

Think about finding a named place.

It directs you to a page and a locator on that page.

2. State the order for reading a four-figure reference.

Help

Across, then up.

Eastings before northings.

3. Read the reference printed for Hall.

Help

Use its left and bottom grid lines to check.

Hall is in 1121.

4. What does the reference identify?

Help

A whole square or an exact doorway?

A whole grid square.

1. How is an atlas index different from its page grid?

Help

Think about the two steps used to find a place.

The index finds the map page and locator; the page grid locates the place on that page.

2. Explain why the order of the numbers matters.

Help

Think about across and up.

The first pair identifies the easting and the second pair the northing; swapping them changes the location.

3. Read Park’s reference and explain each pair.

Help

Check the lines left of and below its square.

Park is in 1122: easting 11, northing 22.

4. Could the grid alone show a safe route through a real place?

Help

Look for paths and entrances.

No. It is an invented practice grid without the detail needed for a safe real route.

Teacher notes and answers

Teacher card

Atlases grid references and digital maps / GROW_SU1_W02

Outcome: Use atlases grid references and digital maps.

Evidence to retain: F: accurate grid references and independent location question.

Forty minute route

Arrival 4 min; starter 3; model 6; shared task 7; check 2; independent 12; review 3; exit 3. Pause time is flexible.

Preparation

Choose one independent route. Print the evidence and shared cards, required visual or data sheet, route worksheet and exit. The organiser is one separate A4 page. Keep answers with staff.

Keep the supplied practice grid unchanged. Prepare the school’s approved mapping tool for a teacher-led demonstration of a public place, with search, zoom and layers where available. Use the School on both fictional comparison cards; do not search for the invented practice place online. If the approved tool is unavailable, compare the supplied cards now and record that the live demonstration needs a later revisit. No pupil searches for a home address.

Access and regulation

Chunk sources and tasks; pre-teach vocabulary with images. Offer sentence stems, organisers, oral rehearsal and typing. Start with one modelled example; extend through a second source, comparison or supported judgement. Check the learner can begin within two minutes, then fade prompts. Begin with a simplified map or data set, then add a stretch layer. Use clear fieldwork roles and a return-to-recording routine.

Offer a predictable start, private response and agreed pause. No cold calling or forced personal disclosure. Rejoin at one clearly named next step. Keep teen-appropriate examples and the same learning goal across response modes.

Use sensitive content warnings where relevant. Do not ask for family details or personal experiences.

Assessment

Use questioning and the exit response to decide the next step. Record the learner’s individual contribution and the access support used.

UAS: no approved unit code is supplied. Match the learner’s evidence to the centre-selected unit and exact criteria before submission. This pack makes no automatic award claim.

grid referenceNumbers or letters used to locate a map square
eastingA grid number read across the map first
northingA grid number read up the map second

Remember

What is the Library’s four-figure reference? Library is in 1021.

Does a four-figure grid reference give the exact entrance position? No. It identifies a square. A more detailed map and a checked entrance location are needed.

A Practice grid method

The practice grid is an invented place. Read eastings across first, then northings up. Use the lines at the left and bottom of the square. Four figures identify a square, not an exact point.

D A route between squares

On the practice grid, start at School. Move one square north to Library, then one square east to Hall. Trace each move and use the printed references. This is a map route, not an outdoor walking instruction.
